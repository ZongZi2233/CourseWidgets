# Version 2.2.5 - 剩余问题修复计划

## 待修复问题

### 1. ⚠️ 手动添加课程教师信息不显示
**问题**: 手动输入的教师数据不能显示，导入的数据却可以
**原因**: 可能是旧数据库没有 teacher 字段
**解决方案**: 添加数据库迁移逻辑，确保旧数据库升级到新结构

### 2. ⚠️ 移除文字下划线
**问题**: 不要给文字加黄色的下划线
**解决方案**: 检查 GlassTextField 的默认样式，移除下划线装饰

### 3. ⚠️ 深色模式玻璃效果
**问题**: 深色模式应该自动调整全局玻璃透明度降低，变黑一点而不是高亮的白
**解决方案**: 
- 创建全局玻璃设置管理器
- 根据深色模式自动调整 glassColor
- 浅色模式: `Colors.white.withValues(alpha: 0.1)`
- 深色模式: `Colors.black.withValues(alpha: 0.3)`

### 4. ⏳ Windows Toast 液态玻璃化
**解决方案**: 修改 `windows_tray_service.dart`，在 UI 层显示液态玻璃 Toast

### 5. ⏳ Windows 托盘问题
**解决方案**: 
- 检查托盘图标路径
- 确保托盘服务正确初始化
- 测试最小化到托盘功能

### 6. ⏳ 主界面拖动透明问题
**解决方案**: 
- 检查滑动监听是否降级渲染
- 确保玻璃效果在拖动时保持
- 调整 GlassQuality 设置

### 7. ⏳ Windows 窗口动画
**解决方案**: 使用 window_manager 的动画 API

### 8. ⏳ Android 导航栏蓝色标签
**解决方案**: 修改 GlassBottomBar 的选中状态样式
