## 技术要点

### 玻璃效果渲染
- 避免使用 alpha 0.0 的完全透明玻璃（会导致灰色渲染错误）
- 推荐使用 alpha 0.2-0.3 的半透明玻璃
- Premium 质量需要更高的参数值（blur, thickness, refractiveIndex）

### Windows 平台
- 窗口需要非透明背景 (alpha 0.01) 才能启用 DWM 动画
- 使用 AnimatedContainer 实现平滑过渡
- 窗口按钮需要足够的背景不透明度才能显示

### 滚动性能
- 使用 RepaintBoundary 隔离重绘区域
- 设置 cacheExtent 预渲染屏幕外内容
- 避免在滚动时禁用物理效果

### AGP 9.0 兼容性
- 移除 buildscript 块
- 不要手动应用 kotlin-android 插件
- 使用 kotlin {} 块代替 kotlinOptions
- 使用 jvmToolchain 指定 JVM 版本
