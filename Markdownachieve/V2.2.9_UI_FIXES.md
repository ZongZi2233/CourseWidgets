# V2.2.9 UI 修复

## 修复的问题

### 1. ✅ 主界面自动刷新问题

**问题：**
- Android/Windows 端点击周次和星期选择器后，课程列表不刷新
- 需要手动切换页面才能看到变化

**原因：**
- `ListView.builder` 没有使用 key，导致 Flutter 认为内容没有变化
- 虽然使用了 `Consumer<ScheduleProvider>`，但 widget 树没有重建

**解决方案：**
```dart
// Android 端
ListView.builder(
  key: ValueKey('schedule_${provider.currentWeek}_${provider.currentDay}'),
  // ...
)

// Windows 端
AdaptiveLiquidGlassLayer(
  key: ValueKey('week_grid_${provider.currentWeek}'),
  // ...
)
```

**效果：**
- 点击周次/星期选择器后立即刷新
- 无需手动切换页面

### 3. ✅ 平板端日历选择器全屏问题

**问题：**
- 平板端日历选择器全屏铺满
- DPI 异常，显示不正常

**原因：**
- 使用 `showCupertinoModalPopup` 在平板上会全屏显示
- 没有响应式布局

**解决方案：**
```dart
Future<DateTime?> showLiquidGlassDatePicker({
  required BuildContext context,
  required DateTime initialDate,
}) async {
  final isTablet = MediaQuery.of(context).size.shortestSide >= 600;
  
  if (isTablet) {
    // 平板模式 - 使用居中对话框
    await showDialog(
      context: context,
      builder: (ctx) => Dialog(
        backgroundColor: Colors.transparent,
        child: ConstrainedBox(
          constraints: const BoxConstraints(
            maxWidth: 400,
            maxHeight: 500,
          ),
          child: // ...
        ),
      ),
    );
  } else {
    // 手机模式 - 使用底部弹窗
    await showCupertinoModalPopup(
      // ...
    );
  }
}
```

**效果：**
- 平板端显示为居中对话框，大小适中
- 手机端保持底部弹窗样式

### 4. ✅ 设置界面动画卡顿问题

**问题：**
- 进入/退出设置二级/三级页面时轻微掉帧
- 动画过快不流畅

**原因：**
- 使用 `MaterialPageRoute` 的默认动画
- 动画时长太短（默认 300ms）
- 动画曲线不够流畅

**解决方案：**
```dart
void _navigateTo(Widget screen) {
  Navigator.push(
    context,
    PageRouteBuilder(
      pageBuilder: (context, animation, secondaryAnimation) => screen,
      transitionsBuilder: (context, animation, secondaryAnimation, child) {
        const begin = Offset(1.0, 0.0);
        const end = Offset.zero;
        final tween = Tween(begin: begin, end: end).chain(
          CurveTween(curve: Curves.easeOutCubic), // 更流畅的曲线
        );
        final offsetAnimation = animation.drive(tween);
        
        return SlideTransition(
          position: offsetAnimation,
          child: child,
        );
      },
      transitionDuration: const Duration(milliseconds: 350), // 更长的动画时长
      reverseTransitionDuration: const Duration(milliseconds: 300),
    ),
  );
}
```

**效果：**
- 动画更流畅，无掉帧
- 时长适中，不会太快或太慢
- 使用 `Curves.easeOutCubic` 提供更自然的缓动

## 技术细节

### Key 的重要性

Flutter 使用 key 来识别 widget 是否需要重建：

```dart
// ❌ 没有 key - Flutter 可能复用旧 widget
ListView.builder(
  itemCount: courses.length,
  itemBuilder: (context, index) => // ...
)

// ✅ 有 key - 强制重建
ListView.builder(
  key: ValueKey('schedule_${provider.currentWeek}_${provider.currentDay}'),
  itemCount: courses.length,
  itemBuilder: (context, index) => // ...
)
```

### 响应式布局

根据屏幕尺寸选择不同的 UI 模式：

```dart
final isTablet = MediaQuery.of(context).size.shortestSide >= 600;

if (isTablet) {
  // 平板布局
} else {
  // 手机布局
}
```

### 动画优化

选择合适的动画曲线和时长：

| 曲线 | 用途 | 特点 |
|------|------|------|
| `Curves.linear` | 匀速运动 | 机械感强 |
| `Curves.easeIn` | 加速进入 | 开始慢，结束快 |
| `Curves.easeOut` | 减速退出 | 开始快，结束慢 |
| `Curves.easeInOut` | 两端缓动 | 开始和结束都慢 |
| `Curves.easeOutCubic` | 三次缓动 | 最流畅自然 |

推荐时长：
- 页面转场：300-400ms
- 小组件动画：200-300ms
- 微交互：100-200ms
