### 完成内容

#### 1. 统一通知管理器 ✅
**文件**: `lib/services/notification_manager.dart`

**功能**:
- 多平台统一接口
- 自动检测平台能力
- 提前通知时间自定义（5/10/15/20/30分钟）
- 双次提醒支持（Android API < 34 和 Windows）
- 通知设置持久化（使用 MMKV）

**支持平台**:
- ✅ Android (所有版本)
- ✅ iOS/iPadOS/macOS
- ✅ Windows

**核心方法**:
```dart
// 初始化
await NotificationManager().initialize();

// 启动课程检查
NotificationManager().startCourseCheck(courses);

// 设置
await NotificationManager().setNotificationEnabled(true);
await NotificationManager().setAdvanceMinutes(15);
await NotificationManager().setDoubleReminder(true);
```

#### 2. Live Activities 服务 ✅
**文件**: `lib/services/live_activities_service.dart`

**功能**:
- iOS Dynamic Island 支持
- Android Live Updates 支持（API 34+）
- 实时倒计时更新
- 上课前 → 上课中自动切换
- 每分钟自动刷新

**状态管理**:
- `upcoming`: 即将上课（60分钟以上）
- `soon`: 马上开始（60分钟内）
- `starting`: 课程开始
- `ongoing`: 正在上课
- `ended`: 课程结束

**数据结构**:
```dart
{
  'courseName': '高等数学',
  'location': '教A-101',
  'teacher': '张教授',
  'status': 'ongoing',
  'timeText': '还有 35 分钟下课',
  'progress': 15,
  'maxProgress': 50,
}
```

### 技术亮点

#### 1. 平台自适应
```dart
// Android API < 34: 双次提醒
if (doubleReminder && Platform.isAndroid) {
  // 第一次：提前 N 分钟
  // 第二次：上课前 5 分钟
}

// Android API ≥ 34: Live Updates
if (Platform.isAndroid && sdkVersion >= 34) {
  // 使用 Live Activities
}

// iOS/macOS: Live Activities
if (Platform.isIOS || Platform.isMacOS) {
  // Dynamic Island
}
```

#### 2. 智能通知管理
```dart
// 避免重复通知
final Set<int> _notifiedCourses = {};

// 自动清理过期记录
if (diff.inMinutes < -60) {
  _notifiedCourses.remove(courseId);
}
```

#### 3. 设置持久化
```dart
// 使用 MMKV 存储
static const String keyNotificationEnabled = 'notification_enabled';
static const String keyAdvanceMinutes = 'notification_advance_minutes';
static const String keyDoubleReminder = 'notification_double_reminder';
```

### 集成指南

#### 1. 初始化通知服务
```dart
// main.dart
await NotificationManager().initialize();
await LiveActivitiesService().initialize();
```

#### 2. 启动课程检查
```dart
// 在 ScheduleProvider 加载数据后
final notificationManager = NotificationManager();
notificationManager.startCourseCheck(provider.courses);
```

#### 3. 启动 Live Activity
```dart
// 获取下一节课
final nextCourse = provider.getNextCourse();

// 启动 Live Activity
if (LiveActivitiesService().isSupported) {
  await LiveActivitiesService().startCourseActivity(nextCourse);
}
```

#### 4. Windows 托盘集成
```dart
// Windows 平台
if (Platform.isWindows) {
  final tray = WindowsTrayService();
  await tray.initialize();
  tray.startCourseReminder(provider);
}
```
