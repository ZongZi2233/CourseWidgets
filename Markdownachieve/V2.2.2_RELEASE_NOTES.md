# CourseWidgets v2.2.2 发布说明

**发布日期**: 2026年1月24日  
**许可证**: Apache 2.0

## 🎉 新功能

### 圆角矩形导航栏
平板端导航栏现在显示为圆角矩形，四周留白，更好地适应大圆角屏幕设备。

### 底部弹出菜单
周次选择器从对话框改为底部弹出菜单，提供更流畅的移动端交互体验。

## 🔧 改进

### 界面简化
- **Android 平板端**: 移除了主界面顶部的"本周课程"横条，界面更简洁
- **设置重组**: 历史记录管理从通用设置移到数据管理，逻辑更清晰

### 渲染优化
- **Windows 端**: 使用 `FakeGlass` 替代原有渲染方式，解决灰条问题
- **About 屏幕**: Touch me 演示使用 `FakeGlass`，视觉效果更好
- **性能提升**: `FakeGlass` 使用 backdrop filters，性能更优

## 🐛 Bug 修复

### Windows 平台
- ✅ 修复主界面网格出现灰条的问题
- ✅ 修复周次选择器对话框圆角不明显的问题

### About 屏幕
- ✅ 修复 Touch me 演示出现灰条的问题
- ✅ 改进玻璃效果渲染质量

### 平板端
- ✅ 修复导航栏在大圆角设备上顶出显示区域的问题
- ✅ 优化导航栏高度和间距

## 📋 技术细节

### FakeGlass 实现
根据 `liquid_glass_renderer` 文档，`FakeGlass` 提供：
- 轻量级玻璃效果
- 更好的跨平台兼容性
- 使用 backdrop filters 而非 shaders
- 适合 Windows/Web 平台

### 底部菜单
使用 `GlassSheet` 实现：
```dart
showModalBottomSheet(
  context: context,
  backgroundColor: Colors.transparent,
  builder: (context) => GlassSheet(
    settings: LiquidGlassSettings(
      glassColor: Colors.black.withValues(alpha: 0.4),
      blur: 20,
      thickness: 15,
    ),
    child: // 内容
  ),
)
```

### 圆角矩形导航栏
```dart
SafeArea(
  child: Padding(
    padding: const EdgeInsets.all(16),
    child: GlassPanel(
      shape: const LiquidRoundedSuperellipse(borderRadius: 32),
      child: Column(
        mainAxisSize: MainAxisSize.min,
        children: [/* 导航项 */],
      ),
    ),
  ),
)
```
