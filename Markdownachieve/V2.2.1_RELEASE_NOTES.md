# CourseWidgets v2.2.1 Release Notes

**Release Date**: January 24, 2026  
**License**: Apache 2.0

## 🎉 What's New

### Premium Liquid Glass Demo
Experience the full power of liquid glass rendering with our new interactive demo in the About screen. Touch it to feel the strong haptic feedback!

### Open Source Release
CourseWidgets is now open source under the Apache 2.0 license! All dependencies are documented and license-compliant.

## 🔧 Improvements

### UI Enhancements
- **Increased Dialog Corner Radius**: All dialogs now have more prominent rounded corners (32px) with superellipse shape
- **Cleaner About Screen**: Removed redundant Core Features and Tech Stack sections for a cleaner look
- **Windows Rendering Fix**: Fixed gray bars issue on Windows - days with courses now show subtle gradients instead

### License & Compliance
- Changed from MIT to Apache 2.0 license
- Added comprehensive third-party license documentation
- All 20+ dependencies verified for license compatibility

## 🐛 Bug Fixes

### Windows Platform
- Fixed gray bars appearing under day headers when courses exist
- Improved day header rendering with gradient backgrounds
- Better visual consistency with Android tablet version

### Dialog System
- Enhanced corner radius visibility across all platforms
- Unified superellipse shape implementation

## 📋 Previous Updates (from v2.2.0)

### Android Tablet/Landscape Mode
- Optimized sidebar height for large-radius devices
- Added SafeArea wrapper to prevent settings overflow
- Implemented swipe gestures for week switching
- Added week picker dialog with 4-column grid
- Fixed week range validation (prevents week 0 or negative weeks)

### Windows Platform
- Cross-platform image picker support
- Replicated Android tablet UI for consistency
- Adjusted background transparency (0.75 → 0.3) for better wallpaper visibility

### Core Updates
- Removed subtitles from data management operations
- Changed semester date picker to liquid glass style
- Unified dialog corner radius system
