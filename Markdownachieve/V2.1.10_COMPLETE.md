### 1. 依赖迁移 - MMKV 存储系统
**目标**: 替代 SharedPreferences，解决 AGP 9.0 兼容性问题，提升性能

#### 实现细节
- ✅ 创建 `lib/services/storage_service.dart` - MMKV 封装服务
- ✅ 支持所有数据类型: String, Int, Bool, Double
- ✅ 在 `main.dart` 中初始化 MMKV
- ✅ 性能提升: MMKV 使用 mmap 技术，比 SharedPreferences 快 10-100 倍

#### API 示例
```dart
final storage = StorageService();
await storage.initialize();

// 存储数据
await storage.setString('key', 'value');
await storage.setInt('count', 42);
await storage.setBool('enabled', true);

// 读取数据
final value = storage.getString('key');
final count = storage.getInt('count', defaultValue: 0);
final enabled = storage.getBool('enabled', defaultValue: false);
```

### 3. 主题系统 - Material You 莫奈取色
**目标**: 支持默认主题、系统主题（Android 12+）、莫奈取色（背景图片）

#### 实现细节
- ✅ 创建 `lib/services/theme_service.dart` - 主题管理服务
- ✅ 三种主题模式:
  - `ThemeMode.defaultMode` - 默认嫩粉色主题
  - `ThemeMode.system` - Android 12+ Material You 动态颜色
  - `ThemeMode.monet` - 从背景图片提取主题色
- ✅ 使用 `dynamic_color: ^1.7.0` 获取系统主题
- ✅ 使用 `image: ^4.3.0` 解析图片
- ✅ 使用 `material_color_utilities: 0.11.1` (Flutter SDK 内置) 生成调色板

#### 主题服务 API
```dart
final themeService = ThemeService();
await themeService.initialize();

// 切换主题模式
await themeService.setThemeMode(ThemeMode.defaultMode);
await themeService.setThemeMode(ThemeMode.system);
await themeService.setThemeMode(ThemeMode.monet);

// 应用系统主题（Android 12+）
await themeService.applySystemTheme(context);

// 从图片提取莫奈颜色
await themeService.extractColorsFromImage('/path/to/image.png');

// 获取当前主题色
Color primary = themeService.primaryColor;
Color secondary = themeService.secondaryColor;
LinearGradient gradient = themeService.getGradient();
```

#### 莫奈取色算法
1. 读取图片文件
2. 缩小图片至 128x128 提升性能
3. 提取所有像素的 ARGB 值
4. 使用 `QuantizerCelebi` 量化颜色（提取 128 种主色）
5. 使用 `Score.score` 评分并选择最佳主色
6. 使用 `CorePalette.of()` 生成 Material You 调色板
7. 提取 primary (40) 和 secondary (40) 色调

## 🔧 技术细节

### 命名冲突解决
**问题**: `ThemeMode` 与 Flutter Material 库冲突

**解决方案**: 使用 import prefix
```dart
import '../../services/theme_service.dart' as theme;

// 使用时添加前缀
theme.ThemeMode _currentThemeMode = theme.ThemeMode.defaultMode;
```

### 图片像素提取
**问题**: `image` 包 API 变更，`pixel.value` 已废弃

**解决方案**: 手动构建 ARGB 值
```dart
final pixel = resized.getPixel(x, y);
final a = pixel.a.toInt();
final r = pixel.r.toInt();
final g = pixel.g.toInt();
final b = pixel.b.toInt();
final argb = (a << 24) | (r << 16) | (g << 8) | b;
```

### Material Color Utilities 版本
**问题**: Flutter SDK 固定使用 0.11.1 版本

**解决方案**: 不在 pubspec.yaml 中显式声明，直接使用 SDK 内置版本
```dart
import 'package:material_color_utilities/material_color_utilities.dart';
```

## 🎨 主题色系统架构

### 颜色流程
```
用户选择主题模式
    ↓
ThemeService.setThemeMode()
    ↓
根据模式设置颜色:
  - defaultMode → 使用默认嫩粉色
  - system → 调用 DynamicColorPlugin.getCorePalette()
  - monet → 调用 extractColorsFromImage()
    ↓
保存到 MMKV 存储
    ↓
AppThemeColors 动态获取
    ↓
UI 组件使用 AppThemeColors.babyPink / softCoral
```

### 主题色应用
```dart
// 在 theme_constants.dart 中
class AppThemeColors {
  // 动态主题色（从 ThemeService 获取）
  static Color get babyPink => ThemeService().primaryColor;
  static Color get softCoral => ThemeService().secondaryColor;
  
  // 渐变
  static LinearGradient get defaultGradient => ThemeService().getGradient();
}
```
