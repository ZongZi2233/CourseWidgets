- 所有玻璃设置统一通过 GlassSettingsHelper 管理

**修改文件**: `lib/utils/glass_settings_helper.dart`

**实现**:
```dart
static LiquidGlassSettings getCardSettings({double? alpha}) {
  final glassColor = globalUseDarkMode
      ? Colors.black.withValues(alpha: alpha ?? 0.3)
      : Colors.white.withValues(alpha: alpha ?? 0.05);
  
  return LiquidGlassSettings(
    glassColor: glassColor,
    blur: 12.0,
    thickness: 0.8,
  );
}
```

2. **系统主题**: Android 12+ Material You 动态颜色（仅 Android）
3. **莫奈取色**: 从背景图片提取主题色

**实现**:
```dart
Widget _buildThemeModeOption(
  theme.ThemeMode mode,
  String title,
  String subtitle,
  IconData icon,
) {
  final isSelected = _selectedThemeMode == mode;
  
  return GestureDetector(
    onTap: () {
      HapticFeedback.selectionClick();
      setState(() => _selectedThemeMode = mode);
    },
    child: Container(
      // 选中状态显示渐变背景和边框
      decoration: BoxDecoration(
        gradient: isSelected ? LinearGradient(...) : null,
        border: Border.all(...),
        borderRadius: BorderRadius.circular(16),
      ),
      child: Row(
        children: [
          // 图标
          Container(...),
          // 标题和副标题
          Expanded(...),
          // 选中标记
          if (isSelected) Icon(Icons.check_circle),
        ],
      ),
    ),
  );
}
```

## 技术要点

### 1. 玻璃效果渲染最佳实践
- **避免 alpha 过低**: alpha < 0.2 容易导致灰块
- **推荐 alpha 范围**: 0.3-0.5 效果最佳
- **Premium 质量参数**:
  - blur: 25+
  - thickness: 35+
  - refractiveIndex: 2.0+
  - lightIntensity: 1.2+
  - ambientStrength: 1.1+

### 2. 深色模式适配
- **深色模式**: 黑色玻璃 (alpha 0.3-0.5)
- **浅色模式**: 白色玻璃 (alpha 0.05-0.15)
- **统一管理**: 使用 GlassSettingsHelper

### 3. 响应式设计
- **横屏检测**: `screenWidth > screenHeight`
- **尺寸限制**: 使用 ConstrainedBox 和百分比
- **平板适配**: `shortestSide >= 600`

### 4. 主题系统
- **三种模式**: 默认/系统/莫奈
- **平台检测**: 系统主题仅 Android 12+
- **自动应用**: 选择后立即应用主题色
