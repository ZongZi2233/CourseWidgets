## 🎯 核心功能实现

### 1. GlassOpacityManager 架构

```dart
class GlassOpacityManager {
  // 单例模式
  static final GlassOpacityManager _instance = GlassOpacityManager._internal();
  
  // 深色模式状态
  bool _isDarkMode = false;
  
  // 监听器列表
  final List<VoidCallback> _listeners = [];
  
  // 核心方法
  void setDarkMode(bool isDark);           // 设置深色模式
  Color getGlassCardColor();               // 获取卡片颜色
  Color getGlassButtonColor();             // 获取按钮颜色
  Color getGlassNavBarColor();             // 获取导航栏颜色
  double getStandardBlur();                // 获取标准模糊度
  double getStandardThickness();           // 获取标准厚度
  void addListener(VoidCallback listener); // 添加监听器
}
```

**使用示例：**
```dart
// 设置深色模式
GlassOpacityManager().setDarkMode(true);

// 获取玻璃颜色
Color cardColor = GlassOpacityManager().getGlassCardColor();
// 深色模式: Colors.black.withValues(alpha: 0.05)
// 浅色模式: Colors.white.withValues(alpha: 0.03)
```

### 2. MMKV 重构实现

**API 对比：**
| 操作 | SharedPreferences | MMKV |
|------|-------------------|------|
| 初始化 | `SharedPreferences.getInstance()` | `MMKV.defaultMMKV()` |
| 读取 int | `prefs.getInt(key)` | `mmkv.decodeInt(key)` |
| 写入 int | `prefs.setInt(key, value)` | `mmkv.encodeInt(key, value)` |
| 读取 String | `prefs.getString(key)` | `mmkv.decodeString(key)` |
| 写入 String | `prefs.setString(key, value)` | `mmkv.encodeString(key, value)` |

**优势：**
- ✅ 解决 AGP 9.0 兼容性问题
- ✅ 统一项目存储方案
- ✅ 性能提升 10-100 倍
- ✅ 减少 7 个依赖包
- ✅ 更好的可靠性

## 📝 重要说明

### 1. Windows 数据持久化

**正常行为：**
- 数据存储在 `AppData/Local/coursewidgets/`
- 清理 build 文件夹不会删除数据
- 这是标准的桌面应用设计

**清除数据方法：**
1. **推荐：** 使用应用内"清除所有数据"功能
2. **手动：** 删除 `AppData/Local/coursewidgets/` 文件夹

### 2. MMKV 存储架构

**课程相关（会被清除）：**
- `semester_start_date` - 开学日期
- `schedule_config` - 课时配置
- `current_week` - 当前周次
- `current_day` - 当前星期

**用户设置（不会被清除）：**
- `dark_mode` - 深色模式
- `adaptive_dark_mode` - 自适应深色模式
- `background_path` - 背景图片路径
- `theme_mode` - 主题模式

### 3. AGP 9.0 兼容性

**已解决的问题：**
- ✅ Workmanager 插件兼容
- ✅ SharedPreferences 依赖移除
- ✅ flutter_foreground_task 重构

**插件修复模式：**
1. 移除 `buildscript` 和 kotlin_version
2. 移除 `apply plugin: 'kotlin-android'`
3. Java 1.8 → Java 21
4. 替换 `kotlinOptions` 为 `kotlin { compilerOptions { jvmTarget = JVM_21 } }`
