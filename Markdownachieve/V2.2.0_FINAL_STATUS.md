## 🎯 课程渲染优化详解

### 之前的实现（可能导致白条）

```dart
MouseRegion(
  cursor: SystemMouseCursors.click,
  child: GestureDetector(
    onTap: () => _showCourseDetail(course),
    child: Container(
      decoration: BoxDecoration(
        color: AppThemeColors.softCoral.withValues(alpha: 0.6),
        borderRadius: BorderRadius.circular(8),
      ),
      child: Text(course.name),
    ),
  ),
)
```

### 现在的实现（应该正常显示）

```dart
Material(
  color: Colors.transparent,
  child: InkWell(
    onTap: () => _showCourseDetail(course),
    borderRadius: BorderRadius.circular(8),
    child: Ink(
      decoration: BoxDecoration(
        gradient: LinearGradient(
          begin: Alignment.topLeft,
          end: Alignment.bottomRight,
          colors: [
            AppThemeColors.softCoral.withValues(alpha: 0.7),
            AppThemeColors.softCoral.withValues(alpha: 0.5),
          ],
        ),
        borderRadius: BorderRadius.circular(8),
        border: Border.all(
          color: Colors.white.withValues(alpha: 0.3),
          width: 1.5,
        ),
        boxShadow: [
          BoxShadow(
            color: AppThemeColors.softCoral.withValues(alpha: 0.3),
            blurRadius: 4,
            offset: const Offset(0, 2),
          ),
        ],
      ),
      child: Text(course.name),
    ),
  ),
)
```

### 关键改进

1. **使用 Material + InkWell**
   - Material 提供正确的渲染上下文
   - InkWell 提供水波纹效果

2. **使用 Ink 装饰器**
   - Ink 确保装饰在 Material 层正确渲染
   - 避免渲染顺序问题

3. **添加渐变色**
   - 从深到浅的渐变
   - 更丰富的视觉效果

4. **添加阴影**
   - 增加立体感
   - 提升视觉层次

5. **添加边框**
   - 半透明白色边框
   - 增强边界感

## 🔧 托盘功能优化详解

### 图标路径查找策略

```dart
// 尝试多个可能的图标路径
final possiblePaths = [
  'data/flutter_assets/assets/app_icon.ico',  // Flutter 打包后的路径
  'assets/app_icon.ico',                       // 开发时的路径
  'app_icon.ico',                              // 备用路径
];

iconPath = possiblePaths.first;
for (final path in possiblePaths) {
  if (await File(path).exists()) {
    iconPath = path;
    debugPrint('找到托盘图标: $path');
    break;
  }
}
```
