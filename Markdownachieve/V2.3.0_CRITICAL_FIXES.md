### ✅ 1. Windows 设置页点击卡片无反应

**问题描述：**
- Windows 端设置页及其二级页面点击卡片没有反应
- 只能通过点击文字或箭头才能使用

**原因分析：**
- `LiquidCard` 的 `onTap` 被子元素阻挡
- 点击事件没有正确传递到整个卡片区域

**解决方案：**
```dart
// 使用 GestureDetector 包裹整个卡片
GestureDetector(
  onTap: onTap,
  behavior: HitTestBehavior.opaque, // 确保整个区域可点击
  child: liquid.LiquidCard(
    // ... 卡片内容
  ),
)
```

**修改文件：**
- `lib/ui/screens/settings_main_screen.dart`
- `lib/ui/screens/settings_data_screen.dart`

**状态：** ✅ 已修复

### ✅ 3. 引导界面个性化设置不能成功

**问题描述：**
- 引导页面的个性化设置（主题色、背景）不能成功保存

**原因分析：**
- 主题设置保存后没有等待确认
- 异步操作可能未完成就跳转

**解决方案：**
```dart
Future<void> _completeOnboarding() async {
  try {
    // 确保主题色模式已保存
    await _themeService.setThemeMode(_selectedThemeMode);
    debugPrint('✅ 主题色模式已保存: $_selectedThemeMode');
    
    // 应用主题色
    if (_selectedThemeMode == theme.ThemeMode.system && Platform.isAndroid) {
      if (mounted) {
        await _themeService.applySystemTheme(context);
      }
    } else if (_selectedThemeMode == theme.ThemeMode.monet && globalBackgroundPath.value != null) {
      await _themeService.extractColorsFromImage(globalBackgroundPath.value!);
    } else if (_selectedThemeMode == theme.ThemeMode.defaultMode) {
      await _themeService.resetToDefaultTheme();
    }
    
    // 等待确保设置已保存
    await Future.delayed(const Duration(milliseconds: 100));
    
    widget.onComplete();
  } catch (e) {
    debugPrint('❌ 完成引导失败: $e');
    if (mounted) {
      LiquidToast.error(context, '设置保存失败: $e');
    }
  }
}
```

**修改文件：**
- `lib/ui/screens/onboarding_theme.dart`

**状态：** ✅ 已修复

### ✅ 6. 新软件不能切换周次和星期 + 课程显示额外信息

**问题描述：**
- 旧软件更新到新版本能够切换主页周次和星期
- 但是安装新软件仍然不能正常切换
- 新版课表会在底部显示额外多余的信息
- 还有 `\n` 这种换行符号

**原因分析：**
- ICS 解析器在提取课程信息时没有清理换行符
- `summary`、`location`、`teacher` 字段包含 `\n` 和 `\r`
- 导致显示时出现换行和额外空格

**解决方案：**
```dart
// 清理换行符和额外空格
final summary = (eventData['summary']?.toString() ?? '未知课程')
    .replaceAll('\n', ' ')
    .replaceAll('\r', ' ')
    .replaceAll(RegExp(r'\s+'), ' ')
    .trim();

final location = (eventData['location']?.toString() ?? '未知地点')
    .replaceAll('\n', ' ')
    .replaceAll('\r', ' ')
    .replaceAll(RegExp(r'\s+'), ' ')
    .trim();

teacher = teacher
    .replaceAll('\n', ' ')
    .replaceAll('\r', ' ')
    .replaceAll(RegExp(r'\s+'), ' ')
    .trim();
```

**修改文件：**
- `lib/services/ics_parser.dart`

**影响：**
- 所有新导入的课程数据将自动清理换行符
- 旧数据需要重新导入才能生效

**状态：** ✅ 已修复
