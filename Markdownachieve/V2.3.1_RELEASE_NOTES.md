## 🐛 Bug 修复

### 1. 引导页玻璃效果
**问题**: 引导页欢迎界面的 CourseWidgets 玻璃块没有玻璃质感和模糊效果

**修复**:
- 使用 `GlassContainer` 替代普通 Container
- 添加 `blur: 20` 模糊效果
- 添加 `thickness: 15` 厚度
- 文字不再换行，布局更美观

### 2. 莫奈取色问题
**问题**: 直接点击莫奈取色选项不会设置成功

**修复**:
- 添加背景图片检查
- 没有背景图片时提示用户先选择
- 避免直接点击莫奈取色失败

### 3. 关于软件 Touch Me 卡片
**问题**: Touch Me 卡片出现灰块渲染错误

**修复**:
- 改用 `GlassContainer` + `GestureDetector`
- 参考导航栏设计
- 确保玻璃效果正确渲染

### 4. 首次进入软件切换问题
**问题**: 首次安装后导入数据，无法切换周次和星期

**修复**:
- 使用 `Future.microtask` 确保异步完成
- 增强调试日志追踪
- 改进数据加载时序

### 5. 深色模式背景亮度
**问题**: 深色模式下背景图片没有变暗

**修复**:
- 深色模式：`alpha: 0.6`（大幅降低亮度）
- 浅色模式：`alpha: 0.2`（轻微降低亮度）
- 使用 `AnimatedContainer` 实现平滑过渡
- 实现 `GlassOpacityManager` 全局管理器

## 📝 已知问题

### 1. 玻璃组件深色模式支持不完整
**描述**: 虽然已经实现了 `GlassOpacityManager`，但大部分组件还没有迁移使用

**影响**: 深色模式下部分组件的玻璃效果不够明显

**计划**: 在后续版本中逐步迁移所有组件

### 2. 首次加载数据切换问题
**描述**: 虽然已经优化，但在某些情况下可能仍然存在问题

**影响**: 首次进入软件后可能无法立即切换周次和星期

**计划**: 需要用户实际测试验证，可能需要进一步优化
