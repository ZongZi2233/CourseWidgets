**问题**: `dynamic_color` 包与 AGP 9.0 的 Kotlin 插件冲突

**解决方案**:
- ✅ 移除 `dynamic_color` 依赖
- ✅ 使用 MethodChannel 直接调用 Android 原生 API
- ✅ 创建 `MainActivity.kt` 获取系统主题色方法
- ✅ 修改 `theme_service.dart` 使用原生方法

**技术实现**:
```kotlin
// MainActivity.kt
@RequiresApi(Build.VERSION_CODES.S)
private fun getSystemAccentColor(): Int {
    return resources.getColor(android.R.color.system_accent1_500, theme)
}
```

```dart
// theme_service.dart
const platform = MethodChannel('com.zongzi.schedule/theme');
final int? systemColor = await platform.invokeMethod('getSystemAccentColor');
```

### 3. Android 16 Live Updates 实时通知

#### 3.1 新通知服务
**文件**: `lib/services/live_notification_service_v2.dart`

**核心功能**:
- ✅ Android 16 Live Updates API
- ✅ 实时倒计时更新（每分钟）
- ✅ 常驻通知栏（ongoing: true）
- ✅ 进度条显示（课程进度/倒计时）
- ✅ 大文本样式（BigTextStyleInformation）
- ✅ 操作按钮（查看详情、关闭）
- ✅ 彩色通知（嫩粉色主题）
- ✅ 点击跳转支持

**通知状态**:
1. **即将上课（> 60分钟）**
   - 标题：⏰ 下节课
   - 内容：课程名
   - 副文本：地点 · 开始时间
   - 进度：0%

2. **即将开始（20-60分钟）**
   - 标题：⏰ 即将开始
   - 内容：课程名
   - 副文本：地点 · 还有 X 分钟
   - 进度：动态计算

3. **马上开始（0-20分钟）**
   - 标题：🔔 马上开始
   - 内容：课程名
   - 副文本：地点 · 还有 X 分钟！
   - 进度：动态计算

4. **正在上课**
   - 标题：📚 正在上课
   - 内容：课程名
   - 副文本：地点 · 还有 X 分钟下课
   - 进度：课程进度

**技术特性**:
```dart
// Android 16 优化配置
AndroidNotificationDetails(
  importance: Importance.high,
  priority: Priority.high,
  ongoing: true,              // 常驻通知栏
  showProgress: true,         // 显示进度条
  visibility: NotificationVisibility.public,
  color: Color(0xFFFF9A9E),  // 嫩粉色
  colorized: true,            // 彩色通知
  styleInformation: BigTextStyleInformation(...),
  actions: [                  // 操作按钮
    AndroidNotificationAction('view_details', '查看详情'),
    AndroidNotificationAction('dismiss', '关闭'),
  ],
)

// 通知点击回调机制
liveService.setOnNotificationTapCallback((course) {
  setState(() => _currentIndex = 0);  // 切换到课程页面
  _showCourseDetailDialog(course);    // 显示课程详情
});
```
