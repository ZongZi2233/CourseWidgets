# Version 2.2.8 - AGP 9.0 Live Activities 修复

## 📋 问题描述

构建 Android 应用时出现 Kotlin 插件冲突错误：

```
FAILURE: Build failed with an exception.

* Where:
Build file 'C:\Users\26390\AppData\Local\Pub\Cache\hosted\pub.dev\live_activities-2.4.6\android\build.gradle' line: 25

* What went wrong:
A problem occurred evaluating project ':live_activities'.
> Failed to apply plugin 'kotlin-android'.
> Cannot add extension with name 'kotlin', as there is an extension already registered with that name.
```

## 🔍 根本原因

### AGP 9.0 的变化
从 Android Gradle Plugin (AGP) 9.0 开始，Kotlin 插件会被**自动应用**到所有 Android 项目中。

```gradle
// AGP 9.0 之前
apply plugin: "com.android.library"
apply plugin: "kotlin-android"  // ✅ 需要手动应用

// AGP 9.0 之后
apply plugin: "com.android.library"
// Kotlin 插件自动应用，无需手动添加
apply plugin: "kotlin-android"  // ❌ 导致冲突！
```

### live_activities 包的问题
`live_activities: ^2.4.6` 包的 `build.gradle` 文件仍然使用旧的配置方式：

```gradle
// plugins/live_activities-2.4.6/android/build.gradle
buildscript {
    dependencies {
        classpath("org.jetbrains.kotlin:kotlin-gradle-plugin:$kotlin_version")  // ❌ 冲突
    }
}

apply plugin: "kotlin-android"  // ❌ 重复应用
```

## ✅ 解决方案

### 方案概述
使用 **dependency_overrides** 覆盖 `live_activities` 包，使用本地修复版本。

### 步骤 1: 复制包到本地
```bash
Copy-Item -Path "C:\Users\26390\AppData\Local\Pub\Cache\hosted\pub.dev\live_activities-2.4.6" -Destination ".\plugins\live_activities-2.4.6" -Recurse -Force
```

### 步骤 2: 修复 build.gradle

**文件**: `plugins/live_activities-2.4.6/android/build.gradle`

#### 修复前

#### 修复后

```gradle
    }
```

**文件**: `pubspec.yaml`

## 🔧 技术细节

### AGP 9.0 的 Kotlin 自动应用机制

AGP 9.0 引入了新的插件管理机制：

```gradle
// AGP 9.0 内部逻辑
if (project.plugins.hasPlugin('com.android.library')) {
    // 自动应用 Kotlin 插件
    project.plugins.apply('org.jetbrains.kotlin.android')
}
```

这意味着：
1. 所有 Android Library 项目自动获得 Kotlin 支持
2. 不需要手动添加 `kotlin-android` 插件
3. 不需要在 buildscript 中添加 Kotlin 插件依赖

### 为什么使用 dependency_overrides？

#### 方案对比

| 方案 | 优点 | 缺点 |
|------|------|------|
| 等待官方更新 | 官方支持 | 时间不确定 |
| Fork 仓库 | 完全控制 | 维护成本高 |
| **dependency_overrides** | ✅ 快速修复<br>✅ 易于维护<br>✅ 不影响其他依赖 | 需要本地文件 |

#### dependency_overrides 工作原理

```yaml
dependencies:
  live_activities: ^2.4.6  # 原始依赖

dependency_overrides:
  live_activities:
    path: plugins/live_activities-2.4.6  # 覆盖为本地版本
```

Flutter 会：
1. 忽略 pub.dev 上的 `live_activities: ^2.4.6`
2. 使用本地路径 `plugins/live_activities-2.4.6`
3. 其他依赖不受影响

### 版本更新说明

#### Kotlin 版本
```gradle
// 旧版本
ext.kotlin_version = "1.8.22"

// 新版本
ext.kotlin_version = "2.0.21"
```

**原因**: Kotlin 2.0+ 与 AGP 9.0 兼容性更好

#### AGP 版本
```gradle
// 旧版本
classpath("com.android.tools.build:gradle:8.1.0")

// 新版本
classpath("com.android.tools.build:gradle:8.7.3")
```

**原因**: 与项目主 AGP 版本保持一致
