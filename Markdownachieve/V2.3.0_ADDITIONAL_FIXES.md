### ✅ 1. 首次激活无法切换周次和星期

**问题描述：**
- 首次激活打开应用（通过引导界面）后，无法切换周次和星期
- 老版本升级却不会有这个问题

**原因分析：**
- `loadSavedData()` 方法没有调用 `_jumpToCurrentDate()`
- 导致首次加载时周次和星期没有正确初始化
- 老版本升级时可能已有保存的周次和星期数据

**解决方案：**
```dart
Future<void> loadSavedData() async {
  try {
    final courses = await _importService.getAllCourses();
    if (courses.isNotEmpty) {
      _courses = courses;
      
      // [v2.3.0修复] 首次加载时也需要跳转到当前日期
      await _jumpToCurrentDate();
    } else {
      // 没有数据时，确保周次和星期有效
      if (_currentWeek < 1) _currentWeek = 1;
      if (_currentDay < 1 || _currentDay > 7) _currentDay = 1;
    }
  } catch (e) {
    _errorMessage = '加载数据失败: $e';
    debugPrint('❌ 加载数据失败: $e');
  }
  
  _isLoading = false;
  notifyListeners();
}
```

**修改文件：**
- `lib/providers/schedule_provider.dart`

**状态：** ✅ 已修复

### ✅ 2. 设置页动画生硬和掉帧

**问题描述：**
- 设置页进入二级菜单时，设置页退出动画生硬闪现
- 切入动画掉帧，帧率低不美观

**原因分析：**
- 使用了复杂的 `PageRouteBuilder` 自定义动画
- 多层 `SlideTransition` 和 `FadeTransition` 嵌套
- 动画计算开销大，导致掉帧

**解决方案：**
```dart
void _navigateTo(Widget screen) {
  // [v2.3.0修复] 使用 MaterialPageRoute 提供原生流畅动画
  Navigator.push(
    context,
    MaterialPageRoute(
      builder: (context) => screen,
    ),
  );
}
```

**优势：**
- 使用 Flutter 原生优化的动画
- 性能更好，无掉帧
- 动画流畅自然
- 退出动画正常工作

**修改文件：**
- `lib/ui/screens/settings_main_screen.dart`

**状态：** ✅ 已修复

### ✅ 4. 课程卡片显示 \n 换行符

**问题描述：**
- 首页课程卡片文本会出现 `\n` 这样的换行符号
- 提取信息不智能

**原因分析：**
- ICS 解析器已修复，但 HTML 导入服务未修复
- HTML 导入时没有清理换行符
- 数据库存储了包含换行符的原始数据

**解决方案：**
```dart
// HTML 导入时清理换行符
String name = (item['courseName'] ?? '')
    .toString()
    .replaceAll('\n', ' ')
    .replaceAll('\r', ' ')
    .replaceAll(RegExp(r'\s+'), ' ')
    .trim();

String location = (item['roomName'] ?? '')
    .toString()
    .replaceAll('\n', ' ')
    .replaceAll('\r', ' ')
    .replaceAll(RegExp(r'\s+'), ' ')
    .trim();

String teacher = (item['teacherName'] ?? '')
    .toString()
    .replaceAll('\n', ' ')
    .replaceAll('\r', ' ')
    .replaceAll(RegExp(r'\s+'), ' ')
    .trim();
```

**修改文件：**
- `lib/services/html_to_ics_converter.dart`
- `lib/services/ics_parser.dart`（已在第一轮修复）

**影响：**
- ✅ ICS 导入：已清理
- ✅ HTML 导入：已清理
- ⚠️ 旧数据：需要重新导入

**状态：** ✅ 已修复
