### 3. ✅ 主界面周次切换增强

**问题**: 缺少便捷的周次切换方式

**解决方案**:
1. **左右滑动切换周次**
   - 向右滑动 → 上一周
   - 向左滑动 → 下一周
   - 使用 `GestureDetector.onHorizontalDragEnd`

2. **点击周次方块打开选择器**
   - 点击当前周次显示网格选择器
   - 4列网格布局
   - 快速跳转到任意周次

**实现代码**:
```dart
// 左右滑动
GestureDetector(
  onHorizontalDragEnd: (details) {
    if (details.primaryVelocity! > 0) {
      // 向右滑动 - 上一周
      _changeWeek(provider, provider.currentWeek - 1);
    } else if (details.primaryVelocity! < 0) {
      // 向左滑动 - 下一周
      _changeWeek(provider, provider.currentWeek + 1);
    }
  },
  child: _buildWeekGrid(context, provider),
)

// 点击打开选择器
GestureDetector(
  onTap: () => _showWeekPicker(context, provider),
  child: Container(...),
)
```

**影响文件**: `lib/ui/widgets/weekly_schedule_grid.dart`

### 4. ✅ 周次切换范围限制

**问题**: Android 横屏端和 Windows 端能够切换到第0周和负数周

**解决方案**:
- 添加周次验证方法 `_changeWeek`
- 使用 `clamp` 限制周次范围
- 防止切换到无效周次

**实现代码**:
```dart
void _changeWeek(ScheduleProvider provider, int targetWeek) async {
  final weeks = await provider.getAvailableWeeks();
  if (weeks.isEmpty) return;
  
  // 限制周次范围，防止切换到第0周或负数周
  final validWeek = targetWeek.clamp(weeks.first, weeks.last);
  
  if (validWeek != provider.currentWeek) {
    HapticFeedback.selectionClick();
    provider.setCurrentWeek(validWeek);
  }
}
```

**影响文件**: 
- `lib/ui/widgets/weekly_schedule_grid.dart`
- `lib/ui/screens/windows_schedule_screen.dart`

## Windows 端额外优化

### 周次选择器增强

**新增功能**:
1. **左右箭头按钮**
   - 快速切换上一周/下一周
   - 自动验证周次范围

2. **长按打开选择器**

**实现**:
```dart

  onTap: () => _changeWeek(provider, provider.currentWeek - 1),

GestureDetector(
  onLongPress: () => _showWeekPicker(context, provider),
  child: GlassButton.custom(...),
)

// 右箭头
GlassButton.custom(
  onTap: () => _changeWeek(provider, provider.currentWeek + 1),
  child: Icon(Icons.chevron_right),
)
```

## 技术细节

### 周次选择器网格布局

**Android 平板**:

- 适合横屏显示

- 负值 → 向左滑动

- 所有周次切换都有触觉反馈
- 使用 `HapticFeedback.selectionClick()`
