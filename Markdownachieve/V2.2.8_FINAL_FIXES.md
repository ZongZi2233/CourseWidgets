**文件**:
- `lib/ui/screens/windows_custom_window.dart`

### 3. AGP 9.0 兼容性问题 ✅
**问题**: `live_activities` 包与 AGP 9.0 冲突  
**修复**:
- 移除 `buildscript` 块
- 使用 `apply plugin` 语法
- 移除 `kotlin-android` 插件
- 使用 `kotlin {}` 块代替 `kotlinOptions {}`
- 更新 Java 版本到 21

**文件**:
- `plugins/live_activities-2.4.6/android/build.gradle`
- `pubspec.yaml` (dependency_overrides)

### 4. 版本号更新 ✅
**问题**: Android 版本号未更新到 2.2.8  
**修复**: 更新所有版本号

**文件**:
- `android/app/build.gradle.kts` - versionCode: 10002208, versionName: "2.2.8"
- `lib/constants/version.dart` - appVersion: '2.2.8', buildNumber: 10002208
- `pubspec.yaml` - version: 2.2.8+10002208

### 5. 引导界面按钮渲染错误 ✅
**问题**: "开始使用" 按钮出现灰色渲染错误  
**原因**: 使用了完全透明的玻璃色 (alpha: 0.0)  
**修复**: 使用主题色 `AppThemeColors.babyPink.withValues(alpha: 0.3)`

**文件**:
- `lib/ui/screens/onboarding_welcome.dart`

### 6. 主界面标题换行问题 ✅
**问题**: "CourseWidgets" 标题可能换行  
**修复**: 
- 使用 `Expanded` 包裹
- 添加 `maxLines: 1`
- 添加 `overflow: TextOverflow.ellipsis`

**文件**:
- `lib/ui/screens/android_liquid_glass_main.dart`

## 🎯 技术细节

### 引导按钮渲染修复

#### 修复前
```dart
settings: LiquidGlassSettings(
  glassColor: Colors.white.withValues(alpha: 0.0), // ❌ 完全透明
  blur: 0,
  thickness: 50,
  refractiveIndex: 2.5,
  lightIntensity: 1.5,
  ambientStrength: 1.2,
),
```

**问题**: 完全透明的玻璃色会导致渲染器降级，显示灰色

#### 修复后
```dart
settings: LiquidGlassSettings(
  glassColor: AppThemeColors.babyPink.withValues(alpha: 0.3), // ✅ 使用主题色
  blur: 20,
  thickness: 15,
),
```

**效果**: 
- 正常的玻璃模糊效果
- 粉色主题色
- 无灰色渲染错误

### 标题不换行修复

#### 修复前
```dart
const Text(
  "CourseWidgets",
  style: TextStyle(...),
),
const Spacer(),
```

**问题**: 在小屏幕或大字体设置下可能换行

#### 修复后
```dart
const Expanded(
  child: Text(
    "CourseWidgets",
    style: TextStyle(...),
    maxLines: 1,
    overflow: TextOverflow.ellipsis,
  ),
),
const SizedBox(width: 12),
```

**效果**:
- 标题占据可用空间
- 最多显示 1 行
- 超出部分显示省略号
- 不会换行
