# Version 2.2.8 紧急修复

## 📋 问题描述

用户报告了两个严重问题：
1. **默认壁纸没有显示** - 背景完全透明
2. **Windows 窗口按钮消失** - 看不到最大化/最小化/关闭按钮

## 🔍 根本原因

### 问题 1: 默认壁纸没有显示
**原因**: 背景图片资源没有在 `pubspec.yaml` 中声明

```yaml
# 缺少的资源
- assets/tahoe.jpg
- assets/mobile wallpaper light.png
```

**影响**:
- Windows 端显示完全透明
- 无法加载默认壁纸
- 用户体验极差

### 问题 2: Windows 窗口按钮消失
**原因**: 窗口背景色 alpha 值过高 (0.7)，导致按钮不可见

```dart
// 问题代码
color: Colors.black.withValues(alpha: 0.7), // ❌ 太暗
```

**影响**:
- 标题栏按钮看不见
- 无法最大化/最小化/关闭窗口
- 用户无法正常使用

### 修复 3: 改进背景加载逻辑

**文件**: `lib/main.dart`

```dart
Future<void> loadGlobalBackground() async {
  try {
    final storage = StorageService();
    final savedPath = storage.getString(StorageService.keyBackgroundPath);
    
    // [v2.2.8修复] 检查是否有用户自定义壁纸
    if (savedPath != null && savedPath.isNotEmpty) {
      // 如果是 asset 路径，直接使用
      if (savedPath.startsWith('asset:')) {
        globalBackgroundPath.value = savedPath;
        debugPrint('✅ 加载默认壁纸: $savedPath');
        return;
      }
      
      // 如果是文件路径，检查文件是否存在
      if (await File(savedPath).exists()) {
        globalBackgroundPath.value = savedPath;
        debugPrint('✅ 加载用户壁纸: $savedPath');
        return;
      }
    }
    
    // [v2.2.8修复] 没有保存的壁纸或文件不存在，使用默认壁纸
    String defaultWallpaper;
    if (Platform.isAndroid || Platform.isIOS) {
      defaultWallpaper = 'asset:assets/mobile wallpaper light.png';
    } else {
      defaultWallpaper = 'asset:assets/tahoe.jpg';
    }
    
    globalBackgroundPath.value = defaultWallpaper;
    debugPrint('✅ 使用默认壁纸: $defaultWallpaper');
  } catch (e) {
    debugPrint('❌ 加载壁纸错误: $e');
    // [v2.2.8修复] 出错时也使用默认壁纸
    String defaultWallpaper;
    if (Platform.isAndroid || Platform.isIOS) {
      defaultWallpaper = 'asset:assets/mobile wallpaper light.png';
    } else {
      defaultWallpaper = 'asset:assets/tahoe.jpg';
    }
    globalBackgroundPath.value = defaultWallpaper;
    debugPrint('✅ 使用默认壁纸 (fallback): $defaultWallpaper');
  }
}
```

## 🔍 技术细节

### 为什么 alpha 0.3 而不是 0.7？

```dart
// alpha 0.7 (70% 不透明)
color: Colors.black.withValues(alpha: 0.7)
// 问题：太暗，按钮看不见

// alpha 0.3 (30% 不透明)
color: Colors.black.withValues(alpha: 0.3)
// 优点：
// 1. 背景壁纸清晰可见
// 2. 窗口按钮清晰可见
// 3. 玻璃效果更明显
// 4. 整体视觉效果更好
```

### 为什么需要在 pubspec.yaml 中声明资源？

```yaml
# Flutter 资源管理机制
assets:
  - assets/tahoe.jpg  # ✅ 必须声明

# 如果不声明：
# 1. AssetImage 无法找到资源
# 2. 运行时抛出异常
# 3. 背景显示失败
```

### 背景加载流程

```
1. 启动应用
   ↓
2. 调用 loadGlobalBackground()
   ↓
3. 检查用户自定义壁纸
   ├─ 有 → 使用用户壁纸
   └─ 无 → 使用默认壁纸
   ↓
4. 设置 globalBackgroundPath
   ↓
5. ValueListenableBuilder 监听变化
   ↓
6. 构建背景 Widget
   ├─ asset: → AssetImage
   ├─ file: → FileImage
   └─ null → Gradient
   ↓
7. LiquidGlassScope.stack 渲染
```

## ⚠️ 注意事项

### 1. 资源文件必须存在
确保以下文件存在于 `assets/` 目录：
- `tahoe.jpg` (Windows/macOS/Linux 默认壁纸)
- `mobile wallpaper light.png` (Android/iOS 默认壁纸)

### 2. 透明度平衡
```dart
// 窗口背景透明度
alpha: 0.3  // ✅ 推荐值

// 太低 (< 0.2)
// - 背景太亮
// - 内容不清晰

// 太高 (> 0.5)
// - 背景太暗
// - 按钮看不见
```

### 3. 调试信息
生产环境可以移除调试信息：
```dart
// 开发环境
debugPrint('🎨 当前背景路径: $backgroundPath');

// 生产环境
// 移除或使用 kDebugMode 包裹
if (kDebugMode) {
  debugPrint('🎨 当前背景路径: $backgroundPath');
}
```
