## 🎉 新功能

### 1. 全局液态玻璃透明度自适应深色模式

**功能描述：**
- 新增 `GlassOpacityManager` 全局玻璃透明度管理器
- 根据深色模式自动调整所有玻璃效果的透明度和颜色
- 深色模式下使用黑色系玻璃，浅色模式下使用白色系玻璃
- 自动调整模糊度和厚度以适应不同模式

**技术实现：**
```dart
// 深色模式
GlassOpacityManager().setDarkMode(true);
Color glassColor = GlassOpacityManager().getGlassCardColor();
// 返回: Colors.black.withValues(alpha: 0.05)

// 浅色模式
GlassOpacityManager().setDarkMode(false);
Color glassColor = GlassOpacityManager().getGlassCardColor();
// 返回: Colors.white.withValues(alpha: 0.03)
```

**影响范围：**
- 所有玻璃卡片
- 导航栏
- 对话框
- 选择器
- Toast 通知

## 🐛 Bug 修复

### 1. Toast 通知黄色双下划线问题

**问题描述：**
- Toast 通知中的文字显示黄色双下划线
- 影响视觉美观

**修复方案：**
```dart
// 使用 DefaultTextStyle 包裹，双重保险移除下划线
DefaultTextStyle(
  style: const TextStyle(
    decoration: TextDecoration.none,
    fontFamily: 'PingFangSC',
  ),
  child: Text(
    message,
    style: const TextStyle(
      decoration: TextDecoration.none,
    ),
  ),
)
```

**修复文件：**
- `lib/ui/widgets/liquid_toast.dart`

## 🔧 技术改进

### 1. 玻璃透明度管理架构

**新增文件：**
- `lib/utils/glass_opacity_manager.dart`

**核心功能：**
```dart
class GlassOpacityManager {
  // 单例模式
  static final GlassOpacityManager _instance = GlassOpacityManager._internal();
  
  // 深色模式状态
  bool _isDarkMode = false;
  
  // 获取玻璃颜色
  Color getGlassCardColor();
  Color getGlassButtonColor();
  Color getGlassNavBarColor();
  Color getGlassDialogColor();
  
  // 获取模糊度和厚度
  double getStandardBlur();
  double getStandardThickness();
  
  // 监听器模式
  void addListener(VoidCallback listener);
  void removeListener(VoidCallback listener);
}
```

### 2. 深色模式同步机制

**流程：**
1. 用户在设置中切换深色模式
2. 更新 `globalUseDarkMode` 全局变量
3. 同步更新 `GlassOpacityManager`
4. 通知所有监听器
5. 所有玻璃组件自动更新

**代码示例：**
```dart
void _toggleDarkMode(bool value) async {
  setState(() {
    globalUseDarkMode = value;
  });
  await _storage.setBool(StorageService.keyDarkMode, value);
  
  // [v2.3.0] 同步更新玻璃透明度管理器
  GlassOpacityManager().setDarkMode(value);
}
```
