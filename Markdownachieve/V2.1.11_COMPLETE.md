```dart
static bool isTabletMode(BuildContext context) {
  final size = MediaQuery.of(context).size;
  final orientation = MediaQuery.of(context).orientation;
  return size.width > tabletBreakpoint && 
         orientation == Orientation.landscape;
}
```

### 5. ScheduleProvider 增强
**文件**: `lib/providers/schedule_provider.dart`

**新增方法**:
```dart
/// 获取指定星期的课程（用于平板模式的周视图）
List<CourseEvent> getCoursesForDay(int day) {
  final weekCourses = getCurrentWeekCourses();
  return weekCourses.where((course) => course.weekday == day).toList();
}
```

**用途**: 支持本周课程网格视图，获取每一天的课程列表
