**修改文件：**

**关键代码：**
```dart
void setCurrentWeek(int week) {
  if (_currentWeek != week) {
    _currentWeek = week;
    debugPrint('📅 切换到第 $week 周');
    notifyListeners();
  }
}

void setCurrentDay(int day) {
  if (day >= 1 && day <= 7 && _currentDay != day) {
    _currentDay = day;
    debugPrint('📅 切换到星期 $day');
    notifyListeners();
  }
}
```
