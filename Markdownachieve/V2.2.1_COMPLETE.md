## 技术细节

### 对话框圆角实现
根据 liquid_glass_widgets 文档，`GlassDialog` 不支持 `shape` 参数，因此使用 `ClipSmoothRect` 包装：
```dart
ClipSmoothRect(
  radius: SmoothBorderRadius(
    cornerRadius: LiquidGlassTheme.largeRadius, // 使用统一的主题常量
    cornerSmoothing: 1.0,
  ),
  child: GlassDialog(
    title: title,
    content: content,
    actions: actions,
    settings: LiquidGlassSettings(...),
  ),
)
```

这样确保对话框的圆角与应用中其他使用 `LiquidGlassTheme.largeRadius` 的 UI 元素完全一致。

### 日期选择器实现
使用自定义的液态玻璃日期选择器：
```dart
final date = await showLiquidGlassCalendarPicker(
  context: context,
  initialDate: _config.semesterStartDate,
);
```
