# Version 2.2.4 升级计划

## 问题清单

### 1. ✅ Windows Toast 通知 - 使用液态玻璃 Toast
**问题**: Windows toast 通知还是原来的 material 不是新的液态玻璃 toast
**解决方案**: 
- 在 Windows 端使用 `LiquidToast` 替代系统通知
- 保留系统托盘通知作为后备

### 2. ✅ Windows 设置界面点击区域
**问题**: Windows 设置界面点方块没用只能点箭头
**解决方案**: 
- 扩大点击区域到整个卡片
- 使用 `InkWell` 或 `GestureDetector` 包裹整个卡片

### 3. ✅ 默认背景壁纸
**问题**: 默认背景不好看
**解决方案**: 
- 手机端: `assets/mobile wallpaper light.png`
- 平板及 Windows: `assets/tahoe.jpg`
- 在 `main.dart` 中根据平台加载默认壁纸

### 4. ✅ Touch Me 预渲染和交互
**问题**: Touch me 没有使用预渲染（出现白闪），并且存在渲染 bug 和没有触控反馈、拉伸效果等
**解决方案**: 
- 使用 `LiquidGlassWidgets.initialize()` 预渲染
- 添加 `HapticFeedback` 触控反馈
- 添加缩放动画效果
- 修复渲染问题

### 5. ⚠️ Windows 托盘问题
**问题**: Windows 托盘仍存在问题，看不见托盘，关闭软件就没有后台了
**解决方案**: 
- 检查托盘图标路径
- 确保托盘服务正确初始化
- 添加调试日志
- 测试最小化到托盘功能

### 6. ⚠️ Windows 窗口动画
**问题**: Windows 端大小化动画仍然消失，最大最小化窗口直接闪现不能自适应的最大化和最小化
**解决方案**: 
- 使用 `window_manager` 的动画 API
- 添加自定义动画过渡
- 可能需要使用 `AnimatedContainer`

### 7. ⚠️ Android 导航栏活动标签
**问题**: 将 Android 端导航栏活动标签页以 ico 和字体变蓝区分（如果不行就算了）
**解决方案**: 
- 修改 `GlassBottomBar` 的选中状态样式
- 使用蓝色图标和文字
- 如果 API 不支持则跳过

### 8. ✅ 添加课程 Toast 通知
**问题**: 添加课程是否成功没有 toast 通知反馈和退出
**解决方案**: 
- 在 `course_edit_screen.dart` 中添加 `LiquidToast.success()`
- 保存成功后自动退出

### 9. ⚠️ 主界面课程块透明问题
**问题**: 主界面触控拉伸拖动课程块时，课程会变得完全透明没有模糊和玻璃效果
**解决方案**: 
- 检查滑动监听是否降级渲染
- 确保玻璃效果在拖动时保持
- 可能需要调整 `GlassQuality` 设置

### 10. ✅ 编辑课程 Toast 通知
**问题**: 编辑课程保存也没有 toast 通知和退出
**解决方案**: 
- 在 `course_edit_screen.dart` 中添加 `LiquidToast.success()`
- 保存成功后自动退出

### 11. ✅ 教师名称显示问题
**问题**: 手动添加和编辑的课程，在主页面和其他显示课程信息的地方不会显示教师名称
**解决方案**: 
- 检查课程卡片组件是否显示 `teacher` 字段
- 确保所有显示课程的地方都包含教师信息
