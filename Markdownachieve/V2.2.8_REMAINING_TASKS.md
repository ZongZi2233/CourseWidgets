## 🔴 任务 1: Windows 窗口动画修复

### 问题描述
Windows 端最大化和最小化时动画消失：
- 最大化：界面完全刷新，相当于闪现再最大化
- 最小化：直接消失，没有动画过渡
- 不像其他原生或非原生的 Windows 应用

### 相关文件
- `lib/ui/screens/windows_custom_window.dart` - Windows 自定义窗口
- `lib/main.dart` - 窗口初始化配置
- `pubspec.yaml` - window_manager 依赖版本

### 当前配置
```dart
// lib/main.dart
WindowOptions windowOptions = const WindowOptions(
  size: Size(1024, 768),
  center: true,
  backgroundColor: Colors.transparent,
  skipTaskbar: false,
  titleBarStyle: TitleBarStyle.hidden,
  windowButtonVisibility: false,
);
```

### 可能的原因
1. `window_manager` 包的配置问题
2. 缺少动画相关的配置选项
3. Windows 平台特定的限制
4. 自定义标题栏导致的问题

### 解决方向
1. **检查 window_manager 文档**
   - 查看是否有动画相关的配置
   - 检查最新版本是否修复了此问题
   - 查看 GitHub Issues 中的相关讨论

2. **尝试配置选项**
   ```dart
   // 可能需要的配置
   WindowOptions(
     // ... 现有配置
     animationDuration: Duration(milliseconds: 300),
     // 或其他动画相关选项
   );
   ```

3. **监听窗口状态变化**
   ```dart
   class WindowsCustomWindow extends StatefulWidget with WindowListener {
     @override
     void onWindowMaximize() {
       // 添加自定义动画
     }
     
     @override
     void onWindowMinimize() {
       // 添加自定义动画
     }
   }
   ```

4. **使用 AnimatedContainer**
   - 在窗口状态变化时使用 AnimatedContainer
   - 平滑过渡尺寸变化

### 测试步骤
1. 点击最大化按钮
2. 观察是否有平滑的放大动画
3. 点击最小化按钮
4. 观察是否有平滑的缩小动画
5. 对比其他 Windows 应用的动画效果

## 🟡 任务 2: 主界面拖动渲染问题

### 问题描述
主界面触控拉伸拖动课程块时：
- 课程会变得完全透明
- 没有模糊效果
- 没有玻璃效果
- 降级渲染

### 对比
- ✅ 日历主界面：拖动正常，保持玻璃效果
- ✅ 设置主界面：拖动正常，保持玻璃效果
- ❌ 主界面：拖动时模糊消失

### 相关文件
- `lib/ui/screens/android_liquid_glass_main.dart` - Android 主界面
- `lib/ui/widgets/weekly_schedule_grid.dart` - 周视图网格

### 当前状态
经过代码检查，发现：
- 主界面和周视图网格中**没有实现拖动功能**
- 没有 `Draggable`、`LongPressDraggable` 或 `ReorderableListView`
- 可能是用户描述的是其他交互（如滚动时的渲染问题）

### 需要明确的问题
1. **拖动功能是否已实现？**
   - 如果未实现，需要先实现拖动功能
   - 如果已实现，需要找到具体代码位置

2. **是否是滚动时的渲染问题？**
   - 滚动时课程卡片是否变透明
   - 是否是性能优化导致的降级渲染

3. **具体的复现步骤**
   - 在哪个页面
   - 如何触发拖动
   - 预期效果 vs 实际效果

### 解决方向

#### 如果是拖动功能
```dart
// 使用 LongPressDraggable
LongPressDraggable<CourseEvent>(
  data: course,
  feedback: Material(
    color: Colors.transparent,
    child: GlassContainer(
      // 保持玻璃效果
      settings: LiquidGlassSettings(...),
      child: CourseCard(course: course),
    ),
  ),
  childWhenDragging: Opacity(
    opacity: 0.5,
    child: CourseCard(course: course),
  ),
  child: CourseCard(course: course),
);
```

#### 如果是滚动渲染问题
```dart
// 确保 ListView 使用正确的物理效果
ListView.builder(
  physics: const BouncingScrollPhysics(),
  cacheExtent: 100, // 增加缓存范围
  // ...
);
```

#### 如果是性能问题
```dart
// 使用 RepaintBoundary 隔离重绘
RepaintBoundary(
  child: CourseCard(course: course),
);
```
