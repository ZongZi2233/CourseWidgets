## Phase 2: 通知系统 ✅

### 1. 统一通知管理器 ✅
**文件**: `lib/services/notification_manager.dart`

**功能**:
- 多平台统一接口（Android/iOS/Windows）
- 自定义提前通知时间（5/10/15/20/30分钟）
- 双次提醒支持（Android API < 34 和 Windows）
- 智能通知去重
- 设置持久化（MMKV）

**核心方法**:
```dart
await NotificationManager().initialize();
NotificationManager().startCourseCheck(courses);
await NotificationManager().setAdvanceMinutes(15);
```

### 2. Live Activities 服务 ✅
**文件**: `lib/services/live_activities_service.dart`

**功能**:
- iOS Dynamic Island 支持
- Android Live Updates 支持（API 34+）
- 实时倒计时更新（每分钟）
- 上课前 → 上课中自动切换

**状态管理**:
- `upcoming`: 即将上课（60分钟以上）
- `soon`: 马上开始（60分钟内）
- `starting`: 课程开始
- `ongoing`: 正在上课
- `ended`: 课程结束

### 3. Windows 托盘服务重构 ✅
**文件**: `lib/services/windows_tray_service.dart`

**改进**:
- 使用统一的 `NotificationManager`

- 添加通知设置入口

### 4. 通知设置页面 ✅

**界面元素**:

## 技术亮点

### 1. 平台自适应
```dart
// 根据平台选择不同实现
if (Platform.isAndroid && sdkVersion >= 34) {
  // Android Live Updates
} else if (Platform.isIOS) {
  // iOS Dynamic Island
} else {
  // 传统通知
}
```

### 2. 智能数据生成
```dart
// 根据当前日期智能生成
final isWeekend = now.weekday >= DateTime.saturday;
if (isWeekend) {
  // 生成下周 + 下下周
} else {
  // 生成本周 + 下周
}
```

### 3. 动画系统
```dart
// 多阶段动画
_logoAnimation: Interval(0.0, 0.6)
_buttonAnimation: Interval(0.5, 1.0)
```

### 4. 状态持久化
```dart
// 使用 MMKV 高性能存储

await _storage.setString(key, value);
```
