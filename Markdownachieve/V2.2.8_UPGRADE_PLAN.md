## 技术要点

### Live Activities 集成
```yaml
dependencies:
  live_activities: ^2.4.6
```

### 深色模式玻璃设置
```dart
// 浅色模式: 白色玻璃，低透明度
glassColor: Colors.white.withValues(alpha: 0.05)

// 深色模式: 黑色玻璃，中等透明度（像晚上的玻璃窗）
glassColor: Colors.black.withValues(alpha: 0.3)
```

### 测试数据生成逻辑
- 检测当前是否周末
- 周末: 生成下周 + 下下周
- 工作日: 生成本周 + 下周
- 每周五天有课（周一到周五）
- 每天 4-6 节课
