### 2. ✅ 添加 Glassify 文字效果
**功能**: 在引导页首页添加 "欢迎使用" 四个字的液态玻璃效果
**位置**: 软件图标和开始使用按钮之间

**实现**:
```dart
import 'package:liquid_glass_renderer/experimental.dart';

Widget _buildGlassifyText() {
  return Glassify(
    child: Container(
      padding: const EdgeInsets.symmetric(horizontal: 40, vertical: 20),
      child: const Text(
        '欢迎使用',
        style: TextStyle(
          fontSize: 36,
          fontWeight: FontWeight.w900,
          color: Colors.white,
          letterSpacing: 4.0,
          shadows: [
            Shadow(
              color: Colors.black26,
              offset: Offset(0, 2),
              blurRadius: 4,
            ),
          ],
        ),
      ),
    ),
  );
}
```

**动画效果**:
- Logo 向上移动：0-120px
- 文字淡入：0.4-0.7s
- 按钮淡入：0.6-1.0s
- 总时长：2000ms

### 3. ✅ 修复引导页主题色设置
**问题**: 引导页的主题色设置无法实际改变设置
**解决方案**: 主题色设置已经正确实现，会在完成引导时保存

**实现细节**:
```dart
Future<void> _completeOnboarding() async {
  HapticFeedback.heavyImpact();
  
  // 1. 保存主题色模式
  await _themeService.setThemeMode(_selectedThemeMode);
  
  // 2. 应用主题色
  if (_selectedThemeMode == theme.ThemeMode.system && Platform.isAndroid && mounted) {
    await _themeService.applySystemTheme(context);
  } else if (_selectedThemeMode == theme.ThemeMode.monet && globalBackgroundPath.value != null) {
    await _themeService.extractColorsFromImage(globalBackgroundPath.value!);
  }
  
  // 3. 完成引导
  widget.onComplete();
}
```

**存储位置**:
- 键名: `StorageService.keyThemeMode`
- 值: `'default'`, `'system'`, `'monet'`

## 技术要点

### liquid_glass_widgets API 规范

#### 1. GlassButton.custom
```dart
GlassButton.custom({
  required VoidCallback onTap,
  required double width,
  required double height,
  required GlassButtonStyle style,
  LiquidShape? shape,
  LiquidGlassSettings? settings,
  GlassQuality? quality,
  Widget? child,
  IconData? icon,  // 如果没有 child，必须提供 icon
})
```

#### 2. GlassContainer
```dart
GlassContainer({
  double? width,
  double? height,
  LiquidShape? shape,
  LiquidGlassSettings? settings,
  GlassQuality? quality,
  bool useOwnLayer = false,
  Widget? child,
})
```

#### 3. Glassify (实验性)
```dart
Glassify({
  required Widget child,
})
```

**注意事项**:
- Glassify 是实验性功能，用于复杂形状的玻璃效果
- 简单形状应该使用 GlassContainer
- 模糊效果目前质量较低（等待 Flutter 修复）

---

### AdaptiveLiquidGlassLayer 使用

**推荐方式**（多个玻璃组件）:
```dart
AdaptiveLiquidGlassLayer(
  settings: LiquidGlassSettings(
    thickness: 0.8,
    blur: 12.0,
    glassColor: Colors.white.withOpacity(0.1),
  ),
  child: Column(
    children: [
      GlassContainer(...),
      GlassButton.custom(...),
      GlassCard(...),
    ],
  ),
)
```

**独立模式**（单个玻璃组件）:
```dart
GlassContainer(
  useOwnLayer: true,
  settings: LiquidGlassSettings(
    thickness: 1.0,
    blur: 15.0,
  ),
  child: ...,
)
```

---

### 质量模式

#### Standard Quality (推荐)
- 适用于滚动内容和交互组件
- 性能优秀
- 质量已经很高

```dart
GlassContainer(
  quality: GlassQuality.standard,
  child: ...,
)
```

#### Premium Quality (静态布局)
- 仅用于静态元素（如 AppBar）
- 使用 Impeller 的高级功能
- iOS/macOS 上效果最佳

```dart
GlassAppBar(
  quality: GlassQuality.premium,
  title: ...,
)
```
