## 技术总结

### 玻璃效果最佳实践
1. **避免完全透明**: alpha 0.0 会导致灰色渲染错误
2. **推荐透明度**: alpha 0.2-0.3 效果最佳
3. **Premium 质量参数**:
   - blur: 25+
   - thickness: 35+
   - refractiveIndex: 2.0+
   - lightIntensity: 1.0+
   - ambientStrength: 1.0+

### Windows 平台优化
1. **窗口背景**: 使用 alpha 0.01 启用 DWM 动画
2. **按钮可见性**: 背景透明度不低于 0.3
3. **动画流畅**: 使用 AnimatedContainer

### 滚动性能优化
1. **RepaintBoundary**: 隔离重绘区域
2. **cacheExtent**: 预渲染屏幕外内容
3. **物理效果**: 始终启用滚动物理

### AGP 9.0 兼容
1. **移除 buildscript**: AGP 9.0 不需要
2. **自动应用插件**: kotlin-android 自动应用
3. **kotlin {} 块**: 替代 kotlinOptions
4. **jvmToolchain**: 指定 JVM 版本
