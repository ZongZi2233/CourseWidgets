## 🔧 技术细节

### Windows 窗口动画原理
```dart
// 1. 设置窗口背景色 (非完全透明)
await windowManager.setBackgroundColor(Colors.black.withValues(alpha: 0.01));

// 2. 使用 AnimatedContainer 平滑过渡
AnimatedContainer(
  duration: const Duration(milliseconds: 200),
  curve: Curves.easeInOut,
  decoration: BoxDecoration(
    color: Colors.black.withValues(alpha: 0.7),
    borderRadius: BorderRadius.circular(borderRadius),
  ),
  // ...
)
```

### 滚动渲染优化原理
```dart
// 1. 使用 RepaintBoundary 隔离重绘
RepaintBoundary(
  child: CourseCard(...),
)

// 2. 增加缓存范围
ListView.builder(
  cacheExtent: 200, // 提前渲染屏幕外 200px 的内容
  // ...
)
```

### 引导流程逻辑
```dart
// 1. 检查是否首次启动
OnboardingService().shouldShowOnboarding

// 2. 显示引导界面
if (shouldShowOnboarding) {
  return OnboardingScreen(onComplete: _completeOnboarding);
}

// 3. 完成后标记
OnboardingService().markOnboardingComplete();
```

## 🐛 已知问题

### Windows 窗口动画
- ⚠️ **系统限制**: window_manager 包不提供原生动画 API
- ⚠️ **DWM 依赖**: 动画效果依赖 Windows DWM 服务
- ⚠️ **透明度影响**: 完全透明的窗口可能无法显示动画
- ✅ **解决方案**: 设置 alpha 0.01 背景色 + AnimatedContainer

### 滚动渲染
- ⚠️ **性能权衡**: RepaintBoundary 增加内存占用
- ⚠️ **缓存范围**: cacheExtent 过大可能影响性能
- ✅ **解决方案**: 平衡缓存范围和性能
