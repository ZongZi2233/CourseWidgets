## 🎯 核心功能

### 1. 玻璃透明度自适应系统

**架构：**
```
GlassOpacityManager (单例)
├── 深色模式状态管理
├── 玻璃颜色配置
│   ├── 卡片颜色
│   ├── 按钮颜色
│   ├── 导航栏颜色
│   ├── 对话框颜色
│   └── 选择器颜色
├── 模糊度配置
│   ├── 标准模糊度
│   ├── 导航栏模糊度
│   └── 对话框模糊度
├── 厚度配置
│   ├── 标准厚度
│   └── 导航栏厚度
└── 监听器模式
    ├── addListener()
    ├── removeListener()
    └── _notifyListeners()
```

**使用示例：**
```dart
// 设置深色模式
GlassOpacityManager().setDarkMode(true);

// 获取玻璃颜色
Color cardColor = GlassOpacityManager().getGlassCardColor();
// 深色模式: Colors.black.withValues(alpha: 0.05)
// 浅色模式: Colors.white.withValues(alpha: 0.03)

// 获取模糊度
double blur = GlassOpacityManager().getStandardBlur();
// 深色模式: 25.0
// 浅色模式: 20.0
```

### 2. Toast 通知优化

**改进：**
- 移除黄色双下划线
- 使用 DefaultTextStyle 确保样式一致
- 指定字体为 PingFangSC

**代码：**
```dart
DefaultTextStyle(

    color: Colors.white,
    fontSize: 14,
    fontWeight: FontWeight.w600,
    decoration: TextDecoration.none,
    fontFamily: 'PingFangSC',
  ),
  child: Text(
    message,
    style: const TextStyle(
      decoration: TextDecoration.none,
    ),
  ),
)
```
