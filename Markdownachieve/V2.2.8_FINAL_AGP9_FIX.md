## 📊 AGP 9.0 关键变化

### 1. Built-in Kotlin
AGP 9.0 内置了 Kotlin 支持，不需要手动应用 `kotlin-android` 插件。

```gradle
// AGP 9.0 内部逻辑
if (project.plugins.hasPlugin('com.android.library')) {
    // 自动应用 Kotlin 插件
    project.plugins.apply('org.jetbrains.kotlin.android')
}
```

### 2. 新的 DSL 接口
AGP 9.0 使用新的 DSL 接口，`kotlinOptions {}` 被废弃。

```gradle
// 旧 DSL（废弃）
kotlinOptions {
    jvmTarget = "11"
}

// 新 DSL（推荐）
kotlin {
    jvmToolchain(21)
}
```

### 3. Flutter 插件的特殊要求
Flutter 插件必须使用传统的 `apply plugin` 语法，不能使用 `plugins {}` 块。

```gradle
// ❌ 不支持
plugins {
    id("com.android.library")
}

// ✅ 必须使用
apply plugin: "com.android.library"
```
