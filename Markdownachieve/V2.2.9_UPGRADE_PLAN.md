## 技术方案

### 1. 平板日历选择器
```dart
// 根据屏幕尺寸调整日历大小
final isTablet = MediaQuery.of(context).size.shortestSide >= 600;
final calendarSize = isTablet ? 400.0 : double.infinity;
final cellSize = isTablet ? 40.0 : 48.0;
```

### 2. 按钮渲染修复
```dart
// 确保使用足够的 alpha 值
glassColor: AppThemeColors.babyPink.withValues(alpha: 0.3)
// 不要使用 alpha: 0.0 或 alpha: 0.1
```

### 3. Toast 下划线
```dart
// 移除 decoration
Text(
  message,
  style: TextStyle(
    color: Colors.white,
    // 不要添加 decoration
  ),
)
```

### 4. 深色模式玻璃透明度
```dart
static LiquidGlassSettings getCardSettings() {
  final isDark = _isDarkMode();
  return LiquidGlassSettings(
    glassColor: isDark 
      ? Colors.white.withValues(alpha: 0.05)  // 深色模式更透明
      : Colors.white.withValues(alpha: 0.03),
    // ...
  );
}
```

### 5. 日历界面尺寸
```dart
// 添加水平 padding
padding: EdgeInsets.symmetric(horizontal: 16),
// 限制课程块高度
height: 80, // 从 100 减少到 80
```

### 6. 引导主题色设置
```dart
// 添加三种模式选择
enum ThemeMode { defaultMode, system, monet }
// 显示选项卡
Row(
  children: [
    _buildThemeModeCard('默认', ThemeMode.defaultMode),
    _buildThemeModeCard('系统', ThemeMode.system),
    _buildThemeModeCard('莫奈', ThemeMode.monet),
  ],
)
```
