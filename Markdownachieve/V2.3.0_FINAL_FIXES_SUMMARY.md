- `lib/ui/screens/settings_data_screen.dart`

```dart
  onTap: onTap,
  behavior: HitTestBehavior.opaque,

  ),
)
```

### 3. 引导界面个性化设置不能成功 ✅

**问题：** 引导页面的个性化设置（主题色、背景）不能成功保存

- 确保异步操作完成后再跳转

- 添加 100ms 延迟确保设置已写入

**修改文件：**
- `lib/ui/screens/onboarding_theme.dart`

**关键改进：**
```dart
try {
  await _themeService.setThemeMode(_selectedThemeMode);
  debugPrint('✅ 主题色模式已保存');
  
  // 应用主题色
  if (_selectedThemeMode == theme.ThemeMode.system) {
    await _themeService.applySystemTheme(context);
  } else if (_selectedThemeMode == theme.ThemeMode.monet) {
    await _themeService.extractColorsFromImage(path);
  }
  
  // 等待确保设置已保存
  await Future.delayed(const Duration(milliseconds: 100));
  
  widget.onComplete();
} catch (e) {
  debugPrint('❌ 完成引导失败: $e');
  LiquidToast.error(context, '设置保存失败: $e');
}
```

### 6. 课程显示额外信息和换行符 ✅

**问题：**
- 新版课表会在底部显示额外多余的信息
- 还有 `\n` 这种换行符号
- 新软件不能正常切换周次和星期

**原因分析：**
- ICS 解析器在提取课程信息时没有清理换行符
- `summary`、`location`、`teacher` 字段包含 `\n` 和 `\r`
- 导致显示时出现换行和额外空格

**解决方案：**
- 在 ICS 解析时清理所有换行符
- 使用正则表达式合并多余空格
- 对所有文本字段进行 trim 处理

**修改文件：**
- `lib/services/ics_parser.dart`

**代码示例：**
```dart
final summary = (eventData['summary']?.toString() ?? '未知课程')
    .replaceAll('\n', ' ')
    .replaceAll('\r', ' ')
    .replaceAll(RegExp(r'\s+'), ' ')
    .trim();

final location = (eventData['location']?.toString() ?? '未知地点')
    .replaceAll('\n', ' ')
    .replaceAll('\r', ' ')
    .replaceAll(RegExp(r'\s+'), ' ')
    .trim();

teacher = teacher
    .replaceAll('\n', ' ')
    .replaceAll('\r', ' ')
    .replaceAll(RegExp(r'\s+'), ' ')
    .trim();
```

**影响：**
- ✅ 所有新导入的课程数据将自动清理
- ⚠️ 旧数据需要重新导入才能生效
