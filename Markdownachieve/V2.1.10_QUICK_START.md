# CourseWidgets v2.1.10 快速开始

## 🎯 核心升级

### 1. MMKV 存储 (替代 SharedPreferences)
```dart
// 初始化（已在 main.dart 中完成）
await StorageService().initialize();

// 使用
final storage = StorageService();
await storage.setString('key', 'value');
String? value = storage.getString('key');
```

### 2. 原生相册选择器 (Android 14+)
```dart
// 请求权限
final ps = await PhotoManager.requestPermissionExtend();

// 选择图片
final result = await AssetPicker.pickAssets(
  context,
  pickerConfig: AssetPickerConfig(
    maxAssets: 1,
    requestType: RequestType.image,
    themeColor: AppThemeColors.babyPink,
  ),
);
```

### 3. 莫奈取色主题系统
```dart
// 切换主题模式
await ThemeService().setThemeMode(ThemeMode.monet);

// 从图片提取颜色
await ThemeService().extractColorsFromImage(imagePath);

// 使用动态颜色
Color primary = AppThemeColors.babyPink; // 自动获取当前主题色
```
