## 测试清单

### 🔥 P0 - 必须测试

#### [ ] Live Update 后台保活（最重要！）

**步骤：**
1. 添加即将开始的课程（5-10分钟后）
2. 启动 Live Update
3. **按 Home 键切换到后台**
4. 观察通知是否持续更新（每5秒）
5. 等待 5-10 分钟
6. 课程结束后确认通知消失

**预期：** ✅ 后台持续更新，不卡住

**如果失败：**
```bash
adb logcat | grep "Live Update"
adb shell dumpsys activity services | grep ForegroundService
```

---
