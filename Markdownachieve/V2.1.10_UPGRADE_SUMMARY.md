## 🎯 核心升级内容

### 1. SharedPreferences → MMKV ✅
**问题**: SharedPreferences 存在 AGP 9.0 兼容性问题，性能较低

**解决方案**:
- ✅ 使用 `mmkv: ^1.3.9` 替代 SharedPreferences
- ✅ 创建 `StorageService` 统一管理键值存储
- ✅ 性能提升：MMKV 基于 mmap，读写速度远超 SharedPreferences
- ✅ 完全兼容 AGP 9.0

**新增文件**:
- `lib/services/storage_service.dart` - MMKV 存储服务封装

**API 对比**:
```dart
// 旧方式 (SharedPreferences)
final prefs = await SharedPreferences.getInstance();
await prefs.setString('key', 'value');
final value = prefs.getString('key');

// 新方式 (MMKV)
final storage = StorageService();
await storage.setString('key', 'value');
final value = storage.getString('key');
```

### 2. ImagePicker → 原生相册选择器 ✅
**问题**: ImagePicker 过于简易，file_picker 不支持 AGP 9.0

**解决方案**:
- ✅ 使用 `wechat_assets_picker: ^9.5.0` + `photo_manager: ^3.5.2`
- ✅ 调用 Android 14+ 原生相册选择器
- ✅ 不申请相册权限，使用系统原生选择器
- ✅ 微信风格的现代化 UI

**特性**:
- 🎨 现代化的图片选择界面
- 📱 Android 14+ 原生体验
- 🔒 无需申请相册权限（使用系统选择器）
- ⚡ 高性能图片加载

**代码示例**:
```dart
// 请求权限

// 选择图片
final List<AssetEntity>? result = await AssetPicker.pickAssets(
```

### 3. 莫奈取色主题系统 ✅
**功能**: 支持动态主题色，包括系统主题和背景图片取色

**三种主题模式**:

#### 3.1 默认主题 (Default)
- 使用应用默认的嫩粉色 + 柔珊瑚色
- 颜色: `#FF9A9E` + `#FAD0C4`

#### 3.2 系统主题 (System) - Android 12+ 专属
- 使用 Android 12+ Material You 动态颜色
- 自动跟随系统壁纸颜色
- 使用 `dynamic_color` 包获取系统调色板

#### 3.3 莫奈取色 (Monet)
- 从背景图片提取主色调
- 使用 Material Color Utilities 生成调色板
- 自动生成协调的次要颜色

**新增文件**:
- `lib/services/theme_service.dart` - 主题服务管理
- 更新 `lib/constants/theme_constants.dart` - 支持动态主题

**技术实现**:
```dart
// 1. 从图片提取颜色
await ThemeService().extractColorsFromImage(imagePath);

// 2. 应用系统主题 (Android 12+)
await ThemeService().applySystemTheme(context);

// 3. 使用动态颜色
Color primaryColor = AppThemeColors.babyPink; // 自动获取当前主题色
LinearGradient gradient = AppThemeColors.defaultGradient; // 动态渐变
```

**莫奈取色算法**:
1. 读取图片并缩小到 128x128（提高性能）
2. 提取所有像素的 ARGB 值
3. 使用 `QuantizerCelebi` 量化颜色（最多 128 种）
4. 使用 `Score.score` 评分并选择主色调
5. 生成 Material You 风格的 `CorePalette`
6. 提取 primary 和 secondary 颜色

## 🔧 技术细节

### StorageService API

#### 基础操作
```dart
// 初始化（在 main.dart 中调用）
await StorageService().initialize();

// String
await storage.setString('key', 'value');
String? value = storage.getString('key', defaultValue: 'default');

// Int
await storage.setInt('key', 123);
int? value = storage.getInt('key', defaultValue: 0);

// Bool
await storage.setBool('key', true);
bool? value = storage.getBool('key', defaultValue: false);

// Double
await storage.setDouble('key', 3.14);
double? value = storage.getDouble('key', defaultValue: 0.0);

// 删除
await storage.remove('key');

// 清空
await storage.clear();

// 检查键是否存在
bool exists = storage.containsKey('key');

// 获取所有键
List<String>? keys = storage.getAllKeys();
```

#### 预定义键
```dart
StorageService.keyDarkMode           // 深色模式
StorageService.keyAdaptiveDarkMode   // 自适应深色模式
StorageService.keyBackgroundPath     // 背景图片路径
StorageService.keyThemeMode          // 主题模式
StorageService.keyCustomThemeColor   // 自定义主题色
```

### ThemeService API

#### 初始化
```dart
// 在 main.dart 中调用
await ThemeService().initialize();
```

#### 获取当前主题色
```dart
Color primary = ThemeService().primaryColor;
Color secondary = ThemeService().secondaryColor;
ThemeMode mode = ThemeService().themeMode;
```

#### 设置主题模式
```dart
// 切换到默认主题
await ThemeService().setThemeMode(ThemeMode.defaultMode);

// 切换到系统主题（Android 12+）
await ThemeService().setThemeMode(ThemeMode.system);
await ThemeService().applySystemTheme(context);

// 切换到莫奈取色
await ThemeService().setThemeMode(ThemeMode.monet);
await ThemeService().extractColorsFromImage(imagePath);
```

#### 获取渐变和半透明色
```dart
LinearGradient gradient = ThemeService().getGradient();
Color primaryAlpha = ThemeService().getPrimaryWithAlpha(0.5);
Color secondaryAlpha = ThemeService().getSecondaryWithAlpha(0.3);
```

#### 重置主题
```dart
await ThemeService().resetToDefault();
```

### AppThemeColors 动态主题

#### 旧方式（静态颜色）
```dart
// v2.1.9 及之前
static const Color babyPink = Color(0xFFFF9A9E);
static const Color softCoral = Color(0xFFFAD0C4);
```

#### 新方式（动态颜色）
```dart
// v2.1.10
static Color get babyPink => ThemeService().primaryColor;
static Color get softCoral => ThemeService().secondaryColor;

// 默认颜色（用于初始化）
static const Color defaultBabyPink = Color(0xFFFF9A9E);
static const Color defaultSoftCoral = Color(0xFFFAD0C4);

// 渐变
static LinearGradient get defaultGradient => ThemeService().getGradient();

// 半透明版本
static Color babyPinkWithAlpha(double alpha) => ThemeService().getPrimaryWithAlpha(alpha);
static Color softCoralWithAlpha(double alpha) => ThemeService().getSecondaryWithAlpha(alpha);
```

## 🚀 性能优化

### MMKV vs SharedPreferences

| 特性 | SharedPreferences | MMKV |
|------|-------------------|------|
| 读写速度 | 慢（基于 XML） | 快（基于 mmap） |
| 内存占用 | 高 | 低 |
| AGP 9.0 兼容 | ❌ 有问题 | ✅ 完全兼容 |
| 多进程支持 | ❌ 不支持 | ✅ 支持 |
| 加密支持 | ❌ 不支持 | ✅ 支持 |

### 莫奈取色性能优化
- 图片缩小到 128x128（减少计算量）
- 异步处理（不阻塞 UI）
- 颜色缓存（避免重复计算）

## 🔄 迁移指南

### 1. SharedPreferences → MMKV

#### 步骤 1: 初始化 StorageService
```dart
// main.dart
void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  // 初始化 MMKV
  await StorageService().initialize();
  
  // ... 其他初始化代码
}
```

#### 步骤 2: 替换所有 SharedPreferences 调用
```dart
// 旧代码
final prefs = await SharedPreferences.getInstance();
await prefs.setString('key', 'value');
final value = prefs.getString('key');

// 新代码
final storage = StorageService();
await storage.setString('key', 'value');
final value = storage.getString('key');
```

### 2. ImagePicker → wechat_assets_picker

#### 步骤 1: 请求权限
```dart
final PermissionState ps = await PhotoManager.requestPermissionExtend();
if (!ps.hasAccess) {
  // 处理权限拒绝
  return;
}
```

#### 步骤 2: 选择图片
```dart
final List<AssetEntity>? result = await AssetPicker.pickAssets(
  context,
  pickerConfig: AssetPickerConfig(
    maxAssets: 1,
    requestType: RequestType.image,
    themeColor: AppThemeColors.babyPink,
  ),
);

if (result != null && result.isNotEmpty) {
  final asset = result.first;
  final file = await asset.file;
  // 使用 file
}
```

### 3. 使用动态主题

#### 步骤 1: 初始化 ThemeService
```dart
// main.dart
void main() async {
```

#### 步骤 2: 使用动态颜色

```dart
    gradient: AppThemeColors.defaultGradient,
```

### 1. material_color_utilities 版本限制

- **影响**: 无影响，0.11.1 功能完整
- **解决**: 使用 Flutter SDK 内置版本

- **问题**: Android 14 以下版本可能需要申请相册权限
- **影响**: 需要在 AndroidManifest.xml 中添加权限声明
- **解决**: 已在代码中处理权限请求
