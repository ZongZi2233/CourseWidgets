### ✅ 6. 深色模式下背景图片亮度调整

**问题**: 
- 深色模式开关改变时，背景图片没有变暗
- 玻璃组件没有响应深色模式变化

**修复方案**:

#### 6.1 背景图片亮度自动调整
- 深色模式：`alpha: 0.6`（大幅降低亮度）
- 浅色模式：`alpha: 0.2`（轻微降低亮度）
- 使用 `AnimatedContainer` 实现平滑过渡

**文件**: `lib/main.dart`

```dart
// [v2.3.0修复] 根据深色模式调整背景亮度
final darkenAlpha = globalUseDarkMode ? 0.6 : 0.2;

backgroundWidget = AnimatedContainer(
  duration: const Duration(milliseconds: 500),
  decoration: BoxDecoration(
    image: DecorationImage(
      image: AssetImage(assetPath),
      fit: BoxFit.cover,
      colorFilter: ColorFilter.mode(
        Colors.black.withValues(alpha: darkenAlpha),
        BlendMode.darken,
      ),
    ),
  ),
);
```

#### 6.2 玻璃组件响应深色模式

**已实现的功能**:
- `GlassOpacityManager` 全局管理器
- 提供不同场景的玻璃颜色配置
- 深色模式使用黑色系玻璃
- 浅色模式使用白色系玻璃

**文件**: `lib/utils/glass_opacity_manager.dart`

**使用方法**:
```dart
// 获取玻璃卡片颜色
Color cardColor = GlassOpacityManager().getGlassCardColor();

// 获取玻璃按钮颜色
Color buttonColor = GlassOpacityManager().getGlassButtonColor();

// 获取文字颜色
Color textColor = GlassOpacityManager().getTextColor();
```

**需要应用的组件**:
- ✅ 主界面背景
- ⚠️ 卡片组件（需要更新）
- ⚠️ 按钮组件（需要更新）
- ⚠️ 对话框（需要更新）
- ⚠️ 底部表单（需要更新）

**建议**: 在后续版本中，逐步将所有玻璃组件迁移到使用 `GlassOpacityManager`，以实现全局统一的深色模式支持。

## 技术细节

### GlassContainer vs GlassButton
- `GlassContainer`: 更稳定，适合静态展示
- `GlassButton`: 有交互效果，但可能存在渲染问题
- 建议: 对于复杂的玻璃效果，优先使用 `GlassContainer` + `GestureDetector`

### 深色模式实现
- 使用 `ColorFilter.mode` 和 `BlendMode.darken` 降低背景亮度
- 深色模式 alpha 值建议: 0.5-0.7
- 浅色模式 alpha 值建议: 0.1-0.3
- 使用 `AnimatedContainer` 实现平滑过渡

### 主题色存储
- 使用 MMKV 存储主题模式和颜色值
- 颜色值使用 `toARGB32()` 转换为整数存储
- 启动时从存储恢复主题设置
