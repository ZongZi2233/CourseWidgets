### 测试 3: Live Update 后台保活 ⭐ 重要

**目标：** 验证 Live Update 通知在后台持续更新

**准备工作：**
1. 添加一节即将开始的测试课程（5-10 分钟后）
2. 确保已授予通知权限

**测试步骤：**
1. 启动应用
2. 进入课程页面
3. 启动 Live Update 通知（应该自动启动）
4. 观察通知栏，确认通知显示
5. **按 Home 键，将应用切换到后台**
6. 观察通知栏的进度条
7. 等待 5-10 分钟，持续观察
8. 课程开始后，观察通知内容变化
9. 课程结束后，观察通知是否消失

**预期结果：**
- ✅ 后台时通知持续更新（每 5 秒）
- ✅ 进度条平滑增长，不会卡住
- ✅ 时间文本实时变化（"还有 X 分钟"）
- ✅ 课程开始后显示"已上课 X 分钟"
- ✅ 课程结束后通知自动消失
- ✅ 前台服务图标显示在状态栏

**调试命令（如果失败）：**
```bash
# 查看前台服务状态
adb shell dumpsys activity services | grep ForegroundService

# 查看通知
adb shell dumpsys notification

# 查看日志
adb logcat | grep "Live Update"
adb logcat | grep "ForegroundTask"
```

**如果失败：**
- 检查 `android/app/src/main/AndroidManifest.xml` 中的前台服务配置
- 检查 `lib/services/live_notification_service_v3.dart`
- 确认 `flutter_foreground_task` 包已正确添加

## 已知问题和限制

### 1. 导航栏边缘锯齿
- **状态：** 已知问题，已应用临时方案
- **原因：** `liquid_glass_widgets` 包的渲染问题
- **影响：** 视觉质量轻微下降
- **计划：** 等待包更新或创建本地覆写版本

### 2. Live Update 电池消耗
- **状态：** 需要长期监控
- **原因：** 前台服务每 5 秒更新一次
- **影响：** 可能增加电池消耗
- **优化：** 已使用 LOW 优先级，最小化唤醒锁
