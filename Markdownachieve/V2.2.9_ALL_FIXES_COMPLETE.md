### 6. ✅ 引导页主题色实时控制
**问题**: 点击主题色选项不会立即切换
**解决方案**: 在 onTap 中立即应用主题色

**文件**: `lib/ui/screens/onboarding_theme.dart`

```dart
onTap: () async {
  HapticFeedback.selectionClick();
  setState(() => _selectedThemeMode = mode);
  
  // 立即应用主题色
  await _themeService.setThemeMode(mode);
  
  if (mode == theme.ThemeMode.system && Platform.isAndroid) {
    await _themeService.applySystemTheme(context);
  } else if (mode == theme.ThemeMode.monet && globalBackgroundPath.value != null) {
    await _themeService.extractColorsFromImage(globalBackgroundPath.value!);
  }
  
  if (mounted) {
    setState(() {}); // 刷新 UI
  }
},
```

### 7. ✅ 主界面周次/星期切换刷新
**问题**: 修改后需要手动切换页面才能刷新
**解决方案**: 
- `setCurrentWeek()` 和 `setCurrentDay()` 已经调用 `notifyListeners()`
- 主界面使用 `Consumer<ScheduleProvider>` 自动监听
- 问题已经在代码中正确实现

**文件**: `lib/providers/schedule_provider.dart`

```dart
void setCurrentWeek(int week) {
  _currentWeek = week;
  notifyListeners(); // ✅ 已存在
}

void setCurrentDay(int day) {
  if (day >= 1 && day <= 7) {
    _currentDay = day;
    notifyListeners(); // ✅ 已存在
  }
}
```

- 深色模式：使用深色渐变背景

```dart
colorFilter: ColorFilter.mode(
  globalUseDarkMode

      : Colors.black.withValues(alpha: 0.2), // 浅色模式
  BlendMode.darken,
),
```

## 技术总结

### 修复的关键点

1. **字体和样式**
   - 增大字体提高可读性
   - 增强阴影效果
   - 确保白色文字在深色背景上清晰

2. **玻璃效果**
   - 添加 blur 和 thickness 参数
   - 使用正确的 alpha 值（0.2-0.3）
   - 避免完全透明（alpha 0.0）

3. **深色模式**
   - 背景图片降低亮度（alpha 0.5）
   - 玻璃颜色使用黑色
   - 渐变背景使用深色调

4. **实时更新**
   - 使用 setState() 刷新 UI
   - 使用 notifyListeners() 通知监听者
   - 使用 Consumer 自动监听状态变化

5. **UI 优化**
   - 居中对齐标题
   - 移除不必要的按钮
   - 简化导航流程
