##### 步骤 5: 实现提前 10 分钟提醒逻辑
```dart
Future<void> checkUpcomingCourses() async {
  final now = DateTime.now();
  final provider = ScheduleProvider();
  await provider.loadSavedData();
  
  final todayCourses = provider.getCurrentDayCourses();
  
  for (var course in todayCourses) {
    final courseStart = DateTime.fromMillisecondsSinceEpoch(course.startTime);
    final difference = courseStart.difference(now);
    
    // 提前 10 分钟提醒
    if (difference.inMinutes >= 10 && difference.inMinutes <= 11) {
      await showUpcomingCourseNotification(course);
    }
  }
}
```

## 📝 注意事项

1. **Android 16 Live Update 兼容性**
   - 需要检查设备是否支持 Live Update
   - 不支持的设备回退到 RemoteView

2. **后台保活限制**
   - Android 12+ 有严格的后台限制
   - 需要申请 SCHEDULE_EXACT_ALARM 权限
   - iOS 后台获取有时间限制

3. **电池优化**
   - 避免频繁唤醒设备
   - 使用合理的检查间隔（5-15 分钟）
   - 提供用户设置选项

4. **权限申请**
   - Android: POST_NOTIFICATIONS, SCHEDULE_EXACT_ALARM
   - iOS: Background Fetch, Push Notifications
   - Windows: 无需特殊权限
