## 🪟 Windows 窗口动画测试

### 测试环境
- **平台**: Windows 10/11
- **分辨率**: 1920x1080 或更高
- **DPI**: 100% / 125% / 150%

### 测试步骤

#### 1. 启动应用
```bash
flutter run -d windows --release
```

#### 2. 测试最大化动画
1. 应用启动后，窗口大小为 1024x768
2. 点击右上角的"最大化"按钮 (□ 图标)
3. **预期效果**:
   - ✅ 窗口平滑放大到全屏
   - ✅ 圆角平滑消失 (16px → 0px)
   - ✅ 动画时长约 200ms
   - ✅ 无闪烁或卡顿
   - ✅ 内容区域平滑过渡

#### 3. 测试还原动画
1. 在最大化状态下，点击"还原"按钮 (⊡ 图标)
2. **预期效果**:
   - ✅ 窗口平滑缩小到 1024x768
   - ✅ 圆角平滑出现 (0px → 16px)
   - ✅ 动画时长约 200ms
   - ✅ 无闪烁或卡顿
   - ✅ 内容区域平滑过渡

#### 4. 测试最小化
1. 点击"最小化"按钮 (- 图标)
2. **预期效果**:
   - ✅ 窗口平滑缩小到任务栏
   - ✅ 系统动画流畅
   - ✅ 托盘图标显示

#### 5. 测试托盘恢复
1. 点击托盘图标
2. **预期效果**:
   - ✅ 窗口从托盘平滑显示
   - ✅ 窗口位置和大小正确
   - ✅ 内容正常显示

#### 6. 重复测试
- 重复步骤 2-5 至少 5 次
- 确保动画稳定，无异常

### 常见问题

#### Q: 动画仍然闪烁？
A: 检查以下设置：
```dart
// lib/main.dart
WindowOptions(
  backgroundColor: Colors.transparent, // 应该是 transparent
  // ...
)

// lib/ui/screens/windows_custom_window.dart
await windowManager.setBackgroundColor(
  Colors.black.withValues(alpha: 0.01) // 应该是 0.01
);
```

#### Q: 圆角没有平滑过渡？
A: 检查 AnimatedContainer 设置：
```dart
AnimatedContainer(
  duration: const Duration(milliseconds: 200), // 应该是 200ms
  curve: Curves.easeInOut, // 应该是 easeInOut
  // ...
)
```

## 📱 主界面滚动测试

### 测试环境
- **平台**: Android / iOS / Windows
- **模式**: 手机模式 + 平板模式

### 准备工作

#### 1. 生成测试数据
1. 首次启动应用，进入引导流程
2. 在导入页面，点击"导入测试数据"
3. 系统会生成本周和下周的模拟课表
4. 确保至少有 10 节课程

#### 2. 或手动添加课程
1. 打开课程表
2. 手动添加至少 10 节课程
3. 分布在不同的时间段

### 测试步骤 - 手机模式

#### 1. 启动应用
```bash
# Android
flutter run -d android --release

# iOS
flutter run -d ios --release
```

#### 2. 进入主界面
1. 应用启动后，默认在"课程"页面
2. 确认显示今天的课程列表

#### 3. 测试慢速滚动
1. 用手指慢速向上滚动课程列表
2. **预期效果**:
   - ✅ 课程卡片保持玻璃效果
   - ✅ 模糊效果稳定
   - ✅ 渐变色正常显示
   - ✅ 无透明或降级渲染
   - ✅ 滚动流畅 60 FPS

#### 4. 测试快速滚动
1. 用手指快速向上滑动 (fling)
2. 观察滚动过程中的渲染
3. **预期效果**:

   - ✅ 模糊效果不消失

#### 5. 测试边界滚动
1. 滚动到列表顶部，继续向下拉
2. 滚动到列表底部，继续向上拉
3. **预期效果**:
   - ✅ 弹性滚动效果正常
   - ✅ 玻璃效果保持
   - ✅ 无渲染异常

#### 6. 测试点击交互
1. 在滚动过程中，点击某个课程卡片
2. **预期效果**:
   - ✅ 滚动立即停止
   - ✅ 课程详情对话框显示
   - ✅ 玻璃效果正常

### 测试步骤 - 平板模式

#### 1. 切换到平板模式
- Android: 使用平板设备或模拟器
- iOS: 使用 iPad 或模拟器

#### 5. 测试周次切换
1. 点击"下一周"按钮
2. 观察课程网格的更新
3. **预期效果**:
   - ✅ 课程数据正确更新
   - ✅ 玻璃效果保持
   - ✅ 无闪烁

### 常见问题

#### Q: 滚动时课程卡片变透明？
A: 检查是否添加了 RepaintBoundary：
```dart
// lib/ui/widgets/weekly_schedule_grid.dart
Widget _buildCourseCard(BuildContext context, CourseEvent course) {
  return RepaintBoundary( // ✅ 必须有
    child: GestureDetector(
      // ...
    ),
  );
}
```

#### Q: 滚动不流畅，帧率低？
A: 检查 cacheExtent 设置：
```dart
// lib/ui/screens/android_liquid_glass_main.dart
ListView.builder(
  cacheExtent: 200, // ✅ 手机模式应该是 200
  // ...
)

// lib/ui/widgets/weekly_schedule_grid.dart
ListView.builder(
  cacheExtent: 100, // ✅ 平板模式应该是 100
  // ...
)
```

#### Q: 玻璃效果完全消失？
A: 检查 LiquidGlassScope 是否正确设置：
```dart
// lib/main.dart
LiquidGlassScope.stack(
  background: backgroundWidget, // ✅ 必须有背景
  content: child ?? const SizedBox(),
)
```
