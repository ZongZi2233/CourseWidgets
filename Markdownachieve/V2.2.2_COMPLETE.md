## 技术实现

### FakeGlass 使用
根据 `liquid_glass_renderer` 文档，`FakeGlass` 是轻量级的玻璃效果替代方案：
- 使用 backdrop filters 而非 shaders
- 更好的性能
- 适合 Windows/Web 平台
- 不支持折射效果，但视觉效果相似

### 底部菜单实现
```dart
showModalBottomSheet(
  context: context,
  backgroundColor: Colors.transparent,
  builder: (context) => GlassSheet(
    settings: LiquidGlassSettings(
      glassColor: Colors.black.withValues(alpha: 0.4),
      blur: 20,
      thickness: 15,
    ),
    child: // 周次网格
  ),
)
```

### 圆角矩形导航栏
```dart
SafeArea(
  child: Padding(
    padding: const EdgeInsets.all(16),
    child: GlassPanel(
      shape: const LiquidRoundedSuperellipse(borderRadius: 32),
      child: Column(
        mainAxisSize: MainAxisSize.min, // 关键：不占满全高
        children: [/* 导航项 */],
      ),
    ),
  ),
)
```
