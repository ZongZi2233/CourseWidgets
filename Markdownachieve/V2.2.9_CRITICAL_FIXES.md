## 修复方案

### 问题 3 & 5: GlassMenu 实现错误

**问题分析：**
- GlassMenu 不应该用 `showCupertinoModalPopup`
- GlassMenu 应该作为 child 包装触发器
- 菜单应该在触发器位置弹出，不是左上角

**正确实现：**
```dart
GlassMenu(
  items: [
    GlassMenuItem(
      title: '编辑课程',
      icon: CupertinoIcons.pencil,
      onTap: () { /* 操作 */ },
    ),
  ],
  child: Container(
    // 触发器按钮
    child: Icon(CupertinoIcons.ellipsis_vertical),
  ),
)
```

### 问题 4: 周次/星期切换不刷新

**问题分析：**
- `setCurrentWeek()` 和 `setCurrentDay()` 已经调用了 `notifyListeners()`
- `_buildSchedulePage()` 使用了 `Consumer<ScheduleProvider>`
- 可能是 `getCurrentDayCourses()` 的逻辑问题

**修复方案：**
1. 检查 `getCurrentDayCourses()` 是否正确过滤课程
2. 确保 `Consumer` 正确监听变化
3. 添加调试日志确认数据变化

### 问题 7: 引导界面主题色被重新初始化

**问题分析：**
- 引导界面设置主题色后，进入主界面被重置
- 可能是 `ThemeService.initialize()` 覆盖了设置

**修复方案：**
```dart
// 在 ThemeService.initialize() 中
Future<void> initialize() async {
  // 加载保存的主题模式
  final savedMode = _storage.getString(StorageService.keyThemeMode);
  if (savedMode != null) {
    _themeMode = ThemeMode.values.firstWhere(
      (e) => e.name == savedMode,
      orElse: () => ThemeMode.defaultMode,
    );
    
    // [修复] 根据保存的模式恢复颜色
    if (_themeMode == ThemeMode.monet) {
      final savedColor = _storage.getInt(StorageService.keyCustomThemeColor);
      if (savedColor != null) {
        _primaryColor = Color(savedColor);
        _secondaryColor = _generateSecondaryColor(_primaryColor);
      }
    }
  }
}
```

### 问题 9: 黄色下划线

**问题分析：**
- Toast 和 Picker 中的文字有黄色下划线
- 可能是 `TextDecoration.underline` 或 debug 模式的溢出警告

**修复方案：**
```dart
// 在所有 Text 组件中明确设置
Text(
  'xxx',
  style: TextStyle(
    decoration: TextDecoration.none, // 明确移除下划线
  ),
)
```

### 问题 10: 实时通知

**问题分析：**
- 当前使用的是进度条通知，不是 Android 16 Live Update
- 提前几小时通知，不是提前 10 分钟
- 关闭软件后没有后台保活

**修复方案：**
这需要完全重写通知系统：

1. **使用 Android 16 Live Update API**
```kotlin
// Android 原生代码
val liveUpdate = LiveUpdate.Builder()
    .setTitle("下节课程")
    .setContent(courseName)
    .setStartTime(startTime)
    .build()

notificationManager.postLiveUpdate(liveUpdate)
```

2. **后台保活**
```dart
// 使用 WorkManager 或 AlarmManager
await AndroidAlarmManager.periodic(
  const Duration(minutes: 5),
  0,
  checkUpcomingCourses,
  wakeup: true,
  rescheduleOnReboot: true,
);
```

3. **桌面小组件**
```kotlin
// Android Widget
class CourseWidget : AppWidgetProvider() {
  override fun onUpdate(context: Context, appWidgetManager: AppWidgetManager, appWidgetIds: IntArray) {
    // 更新小组件
  }
}
```
