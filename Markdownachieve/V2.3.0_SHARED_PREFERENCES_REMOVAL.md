# V2.3.0 移除 SharedPreferences 依赖

## 问题背景

在构建 V2.3.0 时遇到 `shared_preferences_android` 的 AGP 9.0 兼容性问题：

```
FAILURE: Build failed with an exception.
* Where:
Build file 'shared_preferences_android-2.4.20\android\build.gradle' line: 33
* What went wrong:
A problem occurred evaluating project ':shared_preferences_android'.
> Failed to apply plugin 'kotlin-android'.
> Cannot add extension with name 'kotlin', as there is an extension already registered with that name.
```

## 问题分析

### 依赖链

```
flutter_foreground_task
└── shared_preferences
    ├── shared_preferences_android (AGP 9.0 冲突)
    ├── shared_preferences_foundation
    ├── shared_preferences_linux
    ├── shared_preferences_platform_interface
    ├── shared_preferences_web
    └── shared_preferences_windows
```

### 为什么不修复 shared_preferences_android？

1. **项目已使用 MMKV**
   - 项目中已经使用 `mmkv` 作为主要存储方案
   - MMKV 性能更好，功能更强

2. **避免重复依赖**
   - 同时使用 `shared_preferences` 和 `mmkv` 是冗余的
   - 增加 APK 大小

3. **减少 AGP 9.0 兼容性问题**
   - 每个使用 `shared_preferences` 的包都需要修复
   - 不如直接移除依赖

## 解决方案

### 重构 flutter_foreground_task 使用 MMKV

**修改文件：**
1. `plugins/flutter_foreground_task-8.17.0/lib/flutter_foreground_task.dart`
2. `plugins/flutter_foreground_task-8.17.0/pubspec.yaml`

**核心改动：**

#### 1. 替换导入

```dart
// 旧代码
import 'package:shared_preferences/shared_preferences.dart';

// 新代码
import 'package:mmkv/mmkv.dart'; // [v2.3.0修复] 使用 MMKV 替代 SharedPreferences
```

#### 2. 重写存储方法

**getData 方法：**
```dart
// 旧代码
static Future<T?> getData<T>({required String key}) async {
  final SharedPreferences prefs = await SharedPreferences.getInstance();
  await prefs.reload();
  final Object? data = prefs.get(_kPrefsKeyPrefix + key);
  return (data is T) ? data : null;
}

// 新代码
static Future<T?> getData<T>({required String key}) async {
  final mmkv = _getMmkv();
  final String prefsKey = _kPrefsKeyPrefix + key;

  if (T == int) {
    return mmkv.decodeInt(prefsKey) as T?;
  } else if (T == double) {
    return mmkv.decodeDouble(prefsKey) as T?;
  } else if (T == String) {
    return mmkv.decodeString(prefsKey) as T?;
  } else if (T == bool) {
    return mmkv.decodeBool(prefsKey) as T?;
  }

  return null;
}
```

**saveData 方法：**
```dart
// 旧代码
static Future<bool> saveData({
  required String key,
  required Object value,
}) async {
  final SharedPreferences prefs = await SharedPreferences.getInstance();
  await prefs.reload();
  final String prefsKey = _kPrefsKeyPrefix + key;
  
  if (value is int) {
    return prefs.setInt(prefsKey, value);
  } else if (value is double) {
    return prefs.setDouble(prefsKey, value);
  } else if (value is String) {
    return prefs.setString(prefsKey, value);
  } else if (value is bool) {
    return prefs.setBool(prefsKey, value);
  }
  return false;
}

// 新代码
static Future<bool> saveData({
  required String key,
  required Object value,
}) async {
  final mmkv = _getMmkv();
  final String prefsKey = _kPrefsKeyPrefix + key;
  
  if (value is int) {
    return mmkv.encodeInt(prefsKey, value);
  } else if (value is double) {
    return mmkv.encodeDouble(prefsKey, value);
  } else if (value is String) {
    return mmkv.encodeString(prefsKey, value);
  } else if (value is bool) {
    return mmkv.encodeBool(prefsKey, value);
  }
  return false;
}
```

**getAllData 方法：**
```dart
// 新代码
static Future<Map<String, Object>> getAllData() async {
  final mmkv = _getMmkv();
  final Map<String, Object> dataList = {};
  
  final keys = mmkv.allKeys ?? [];
  for (final String key in keys) {
    if (key.contains(_kPrefsKeyPrefix)) {
      // 尝试不同类型的解码
      final intValue = mmkv.decodeInt(key);
      if (intValue != null) {
        final String originKey = key.replaceAll(_kPrefsKeyPrefix, '');
        dataList[originKey] = intValue;
        continue;
      }
      
      final doubleValue = mmkv.decodeDouble(key);
      if (doubleValue != null) {
        final String originKey = key.replaceAll(_kPrefsKeyPrefix, '');
        dataList[originKey] = doubleValue;
        continue;
      }
      
      final stringValue = mmkv.decodeString(key);
      if (stringValue != null) {
        final String originKey = key.replaceAll(_kPrefsKeyPrefix, '');
        dataList[originKey] = stringValue;
        continue;
      }
      
      final boolValue = mmkv.decodeBool(key);
      if (boolValue != null) {
        final String originKey = key.replaceAll(_kPrefsKeyPrefix, '');
        dataList[originKey] = boolValue;
        continue;
      }
    }
  }

  return dataList;
}
```

#### 3. 添加 MMKV 实例管理

```dart
static MMKV? _mmkv;

static MMKV _getMmkv() {
  _mmkv ??= MMKV.defaultMMKV();
  return _mmkv!;
}
```

## API 对比

### SharedPreferences vs MMKV

| 操作 | SharedPreferences | MMKV |
|------|-------------------|------|
| 初始化 | `SharedPreferences.getInstance()` | `MMKV.defaultMMKV()` |
| 读取 int | `prefs.getInt(key)` | `mmkv.decodeInt(key)` |
| 写入 int | `prefs.setInt(key, value)` | `mmkv.encodeInt(key, value)` |
| 读取 String | `prefs.getString(key)` | `mmkv.decodeString(key)` |
| 写入 String | `prefs.setString(key, value)` | `mmkv.encodeString(key, value)` |
| 读取 bool | `prefs.getBool(key)` | `mmkv.decodeBool(key)` |
| 写入 bool | `prefs.setBool(key, value)` | `mmkv.encodeBool(key, value)` |
| 读取 double | `prefs.getDouble(key)` | `mmkv.decodeDouble(key)` |
| 写入 double | `prefs.setDouble(key, value)` | `mmkv.encodeDouble(key, value)` |
| 删除 | `prefs.remove(key)` | `mmkv.removeValue(key)` |
| 获取所有键 | `prefs.getKeys()` | `mmkv.allKeys` |
| 重新加载 | `prefs.reload()` | 不需要 |

### 主要区别

1. **异步 vs 同步**
   - SharedPreferences: 异步操作（`async/await`）
   - MMKV: 同步操作（但我们保持 `async` 接口兼容性）

2. **性能**
   - SharedPreferences: 基于 XML 文件，较慢
   - MMKV: 基于 mmap，非常快

3. **可靠性**
   - SharedPreferences: 可能丢失数据
   - MMKV: 更可靠，支持多进程

- 💡 如果需要，可以手动迁移：
  ```dart
  // 从 SharedPreferences 迁移到 MMKV
  final prefs = await SharedPreferences.getInstance();
  final mmkv = MMKV.defaultMMKV();
  
  for (final key in prefs.getKeys()) {
    if (key.startsWith('com.pravera.flutter_foreground_task.prefs.')) {
      final value = prefs.get(key);
      if (value is int) mmkv.encodeInt(key, value);
      else if (value is double) mmkv.encodeDouble(key, value);
      else if (value is String) mmkv.encodeString(key, value);
      else if (value is bool) mmkv.encodeBool(key, value);
    }
  }
  ```

## 注意事项

### 1. MMKV 初始化
- MMKV 需要在 `main()` 中初始化
- 项目中已经初始化，无需额外操作

### 2. 类型安全
- MMKV 的 `decode` 方法返回 `null` 而不是默认值
- 需要正确处理 `null` 情况

### 3. 测试
- 需要测试 Live Update 功能
- 确保数据正确保存和读取
