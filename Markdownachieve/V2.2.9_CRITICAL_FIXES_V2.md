### 2. Live Update 后台保活修复 ⭐

**问题分析：**

#### UI 层面 ✅
- 代码完全符合 Android Live Update 规范
- 正确使用 `ongoing: true` 和 `showProgress: true`
- 通知显示完美

#### 生命周期层面 ❌
- 使用 `Timer.periodic` 在 Dart 层更新通知
- 当 App 切换到后台，Android 系统会挂起 Dart Isolate
- 导致定时器停止，通知不再更新
- 用户体验：通知卡在最后一分钟，直到重新打开 App

**Android 规范要求：**
> Live Update = Notification UI + Foreground Service

长时间运行且需要频繁更新的通知（导航、音乐、实时追踪）必须绑定前台服务。

**解决方案：**

#### 方案选择
采用 `flutter_foreground_task` 包实现前台服务：
- ✅ 标准的 Flutter 解决方案
- ✅ 跨平台支持（Android/iOS）
- ✅ 自动处理生命周期
- ✅ 支持 Isolate 独立运行

#### 架构设计
```
┌─────────────────────────────────────┐
│   LiveNotificationServiceV3         │
│   (主服务控制器)                     │
└──────────────┬──────────────────────┘
               │
               ├─► Foreground Service
               │   (保持后台运行)
               │
               ├─► Notification
               │   (显示实时进度)
               │
               └─► Isolate
                   (独立线程更新)
```

#### 实现细节

**1. 添加依赖**
```yaml
dependencies:
  flutter_foreground_task: ^8.15.0
```

**2. 配置 AndroidManifest.xml**
```xml
<!-- 权限 -->
<uses-permission android:name="android.permission.FOREGROUND_SERVICE"/>
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_DATA_SYNC"/>

<!-- 服务声明 -->
<service
    android:name="com.pravera.flutter_foreground_task.service.ForegroundService"
    android:foregroundServiceType="dataSync"
    android:exported="false"
    android:stopWithTask="true" />
```

**3. 服务初始化**
```dart
FlutterForegroundTask.init(
  androidNotificationOptions: AndroidNotificationOptions(
    channelId: 'live_update_channel',
    channelName: 'Live Update',
    channelImportance: NotificationChannelImportance.LOW,
  ),
  foregroundTaskOptions: ForegroundTaskOptions(
    eventAction: ForegroundTaskEventAction.repeat(5000), // 每5秒更新
    allowWakeLock: true,
  ),
);
```

**4. 启动前台服务**
```dart
await FlutterForegroundTask.startService(
  serviceId: 256,
  notificationTitle: '课程提醒',
  notificationText: '正在监控课程: ${course.name}',
  callback: startCallback, // 独立 Isolate 回调
);
```

**5. 任务处理器**
```dart
class LiveUpdateTaskHandler extends TaskHandler {
  @override
  void onRepeatEvent(DateTime timestamp) {
    // 每5秒执行一次
    _updateNotification();
  }
  
  Future<void> _updateNotification() async {
    // 计算进度
    final progress = ...;
    
    // 更新通知
    await _notifications.show(
      1001,
      courseName,
      timeText,
      NotificationDetails(
        android: AndroidNotificationDetails(
          'live_update_channel',
          'Live Update',
          ongoing: true,
          showProgress: true,
          progress: progress,
        ),
      ),
    );
  }
}
```

#### 工作流程

1. **前台运行**
   - App 在前台时，前台服务正常运行
   - 每 5 秒更新一次通知进度

2. **后台运行**
   - App 切换到后台，前台服务继续运行
   - Isolate 独立于主线程，不会被挂起
   - 通知持续更新，用户可以看到实时进度

3. **课程结束**
   - 检测到课程结束时间
   - 自动停止前台服务
   - 清除通知

#### 性能优化

- 更新频率：5 秒（平衡实时性和性能）
- 通知优先级：LOW（不打扰用户）
- 唤醒锁：仅在更新时短暂持有
- 自动停止：课程结束后立即释放资源
