## 📊 Windows 降级策略说明

### 为什么需要降级策略？

在 Windows 平台上，`liquid_glass_widgets` 的某些组件（如 `GlassButton`、`GlassContainer`）可能会导致 Skia 渲染失败，表现为：
- 组件显示为灰条
- 内容无法渲染
- 性能问题

### 降级策略内容

1. **不使用 `GlassButton`**
   - 替代方案: `Container` + `GestureDetector` + `MouseRegion`
   - 保留视觉效果: 使用 `BoxDecoration` 实现圆角、边框、颜色

2. **不使用 `GlassContainer`**
   - 替代方案: `Container` + `BoxDecoration`
   - 保留视觉效果: 使用半透明颜色 + 边框

3. **不使用 `GlassTextField`**
   - 替代方案: 原生 `TextField` + 自定义 `InputDecoration`
   - 保留视觉效果: 使用半透明背景 + 自定义边框

4. **保留液态玻璃效果的组件**
   - 侧边栏导航: 使用 `GlassContainer` (简单布局，渲染稳定)
   - 对话框: 使用 `LiquidGlassDialog` (独立渲染上下文)
   - Toast: 使用 `GlassContainer` (简单布局，短时间显示)

### 降级策略效果

- ✅ 课程卡片正常显示，无灰条
- ✅ 按钮可点击，有视觉反馈
- ✅ 输入框正常工作
- ✅ 保留液态玻璃风格的视觉效果
- ✅ 性能稳定，无渲染问题
