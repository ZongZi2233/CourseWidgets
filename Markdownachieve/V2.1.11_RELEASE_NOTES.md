## ✨ 新增功能

### 1. Android 平板完整适配 🖥️
全新的平板体验，充分利用大屏幕空间！

#### 智能响应式布局
- 自动检测屏幕尺寸和方向
- 横屏（宽度 > 600dp）自动切换平板模式
- 竖屏保持原有手机布局

#### 平板专属侧边栏
- 80dp 宽度液态玻璃侧边栏
- 三个导航标签（课程、日历、设置）
- 选中状态光晕效果
- 流畅的切换动画

#### 本周课程网格视图
- 7 列布局，一周课程一目了然
- 周次快速切换（上一周、本周、下一周）
- 课程卡片显示节次、课程名、地点
- 点击查看详情

#### 日历分屏视图
- 左侧日历选择器（45% 宽度）
- 右侧课程列表（55% 宽度）
- 同屏显示，操作更便捷

### 2. Android 16 Live Updates 实时通知 🔔
类似 iOS 灵动岛的实时课程提醒！

#### 四种智能状态
1. **即将上课**（> 60分钟）
   - 显示下节课信息和开始时间
   
2. **即将开始**（20-60分钟）
   - 倒计时提醒
   - 动态进度条
   
3. **马上开始**（0-20分钟）
   - 紧急提醒
   - 加速进度条
   
4. **正在上课**
   - 显示剩余时间
   - 课程进度条

#### 实时更新
- 每分钟自动更新通知内容
- 常驻通知栏，不可滑动删除
- 彩色主题（嫩粉色 #FF9A9E）
- 大文本样式，信息更丰富

#### 交互功能
- 点击通知跳转到课程详情
- "查看详情"按钮快速查看
- "关闭"按钮停止通知

### 3. AGP 9.0 完全兼容 🔧
解决了构建工具兼容性问题！

- 移除 `dynamic_color` 依赖
- 使用原生 MethodChannel 获取系统主题色
- 完全兼容 AGP 9.0 和 Kotlin 2.0
- 编译速度更快，更稳定

## 📦 下载

### Android APK
- **ARM64**: `app-arm64-v8a-release.apk` (推荐)
- **x86-64**: `app-x86_64-release.apk` (模拟器)

### 构建命令
```bash
# Android ARM64
flutter build apk --release --target-platform android-arm64 --split-per-abi --obfuscate --split-debug-info=build/debug_info

# Windows
flutter build windows --release --obfuscate --split-debug-info=build/debug_info
```

## 🎯 使用指南

### 平板模式
1. 横屏打开应用
2. 左侧导航栏选择功能
3. 右侧查看内容
4. 本周课程网格一目了然

### 实时通知
1. 首次启动授予通知权限
2. 导入课程数据
3. 通知自动显示下节课信息
4. 点击通知查看详情

### 导入课程
1. 进入设置 → 数据管理
2. 选择导入方式（ICS 或 HTML）
3. 选择文件
4. 自动解析并保存

## ⚠️ 注意事项

### 权限要求
- **通知权限**: 必需，用于实时课程提醒
- **存储权限**: 导入文件时需要

### 系统要求
- Android 14+ 才能使用所有功能
- Android 16 体验最佳（Live Updates）
- 平板建议屏幕尺寸 ≥ 8 英寸

### 电池优化
- 建议关闭应用的电池优化
- 确保后台通知正常工作
