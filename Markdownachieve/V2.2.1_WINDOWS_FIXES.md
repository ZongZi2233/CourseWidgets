# 版本 2.2.1 Windows 平台修复

## 修复日期
2026-01-24

## 修复内容

### 1. ✅ 图片选择功能跨平台支持

**问题**: 图片选择只支持 Android 平台，Windows/macOS/Linux 无法使用

**解决方案**:
- 添加 `file_selector` 包支持
- Windows/macOS/Linux 使用 `openFile` API
- Android 继续使用原生 Photo Picker

**代码实现**:
```dart
if (Platform.isAndroid) {
  // Android 14+ Photo Picker
  const platform = MethodChannel('com.zongzi.schedule/image_picker');
  final String? imagePath = await platform.invokeMethod('pickImage');
} else if (Platform.isWindows || Platform.isMacOS || Platform.isLinux) {
  // 桌面平台使用 file_selector
  final XFile? file = await openFile(
    acceptedTypeGroups: [
      const XTypeGroup(
        label: '图片',
        extensions: ['jpg', 'jpeg', 'png', 'bmp', 'webp'],
      ),
    ],
  );
}
```

**影响文件**:
- `lib/ui/screens/settings_general_screen.dart`

### 2. ✅ Windows 主界面渲染优化

**问题**: 
- Windows 主界面有课日期显示灰色条，视觉效果不佳
- 与 Android 平板端的精美设计不一致

**解决方案**:
- 完全复刻 Android 平板端的代码
- 使用 `GlassPanel` 和 `GlassContainer` 组件
- 有课日期使用渐变背景而非灰色条
- 今日日期使用粉色渐变高亮

**关键改进**:
1. **周次选择器**: 使用 `GlassButton` + 圆形光晕效果
2. **课程网格**: 使用 `GlassPanel` 包装，添加模糊效果
3. **日期标题**: 今日使用渐变背景，有课日期使用淡色背景
4. **课程卡片**: 使用 `GlassContainer` + 边框 + 阴影

**视觉对比**:

修复前:
```
- 灰色条背景（不美观）
- 简单容器（无玻璃效果）
- 平淡的视觉效果
```

修复后:
```
- 渐变背景（今日）
- 液态玻璃效果
- 圆形光晕选中效果
- 精美的视觉呈现
```

**影响文件**:
- `lib/ui/screens/windows_schedule_screen.dart`

---

### 3. ✅ 背景遮罩透明度统一

**问题**:
- 一级界面（主窗口）有不透明色遮罩（alpha: 0.75）
- 二级界面（设置等）没有遮罩，显得巨亮
- 视觉不统一，体验不佳

**解决方案**:
- 将主窗口背景透明度从 0.75 降低到 0.3
- 使用极淡的背景，让壁纸更清晰可见
- 统一一级和二级界面的视觉效果

**代码修改**:
```dart
// 修复前
color: Colors.black.withValues(alpha: 0.75),  // 太暗

// 修复后
color: Colors.black.withValues(alpha: 0.3),   // 极淡
```

**视觉效果**:
- 壁纸更清晰可见
- 液态玻璃效果更明显
- 整体视觉更通透
- 一级和二级界面协调统一

**影响文件**:
- `lib/ui/screens/windows_custom_window.dart`
