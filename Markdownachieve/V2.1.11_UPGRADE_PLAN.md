## 🎯 核心功能

### 1. Android 平板横屏适配

#### 1.1 左侧导航栏（类似 Windows）
**目标**: 平板横屏时，导航栏移到左侧，不占用过多空间

**实现方案**:
- 检测屏幕宽度 > 600dp 时启用平板模式
- 使用 `Row` 布局：左侧导航栏 + 右侧内容区
- 导航栏宽度：80dp（仅图标）或 200dp（图标+文字）
- 使用 `GlassSideBar` 组件实现液态玻璃效果

**文件**: `lib/ui/screens/android_liquid_glass_main.dart`

#### 1.2 主页显示本周所有课程（类似 Windows）
**目标**: 平板模式下，主页显示本周 7 天课程网格，而非单日列表

**实现方案**:
- 7 列网格布局，每列代表一天（周一到周日）
- 每个课程卡片显示：节次、课程名、地点
- 添加周次切换按钮（上一周、本周、下一周）
- 使用 `GridView` 或 `Row` + `Column` 实现

**文件**: `lib/ui/screens/android_liquid_glass_main.dart`

#### 1.3 日历页面左右分屏
**目标**: 日历选择器在左侧，当日课程列表在右侧，55 分屏

**实现方案**:
- 使用 `Row` 布局：左侧日历（45%）+ 右侧课程列表（55%）
- 日历选择器保持现有功能
- 右侧课程列表使用 `ListView` 显示选中日期的课程

**文件**: `lib/ui/screens/calendar_view_screen.dart`

#### 1.4 课程设置开学日期选择器迁移
**目标**: 将 Cupertino 日期选择器迁移到液态玻璃风格

**实现方案**:
- 使用 `lib/ui/widgets/liquid_glass_pickers.dart` 中的 `LiquidGlassDatePicker`
- 替换 `showDatePicker` 为自定义液态玻璃选择器

## 🔧 技术细节

### 平板检测逻辑
```dart
bool isTablet(BuildContext context) {
  final width = MediaQuery.of(context).size.width;
  final orientation = MediaQuery.of(context).orientation;
  return width > 600 && orientation == Orientation.landscape;
}
```

### 响应式布局
```dart
Widget build(BuildContext context) {
  final isTabletMode = isTablet(context);
  
  if (isTabletMode) {
    return Row(
      children: [
        // 左侧导航栏
        GlassSideBar(...),
        // 右侧内容区
        Expanded(child: _buildContent()),
      ],
    );
  } else {
    // 手机模式：底部导航栏
    return Scaffold(
      body: _buildContent(),
      bottomNavigationBar: GlassBottomBar(...),
    );
  }
}
```

### Android 16 Live Updates 通知
```dart
class LiveNotificationService {
  static const String channelId = 'course_live_updates';
  static const String channelName = '课程实时提醒';
  
  Future<void> initialize() async {
    // 创建 Android 16 Live Updates 通知通道
    const androidChannel = AndroidNotificationChannel(
      channelId,
      channelName,
      description: '实时显示课程倒计时和提醒',
      importance: Importance.high,
      enableLights: true,
      enableVibration: false,
      playSound: false,
      showBadge: false,
    );
    
    await flutterLocalNotificationsPlugin
        .resolvePlatformSpecificImplementation<
            AndroidFlutterLocalNotificationsPlugin>()
        ?.createNotificationChannel(androidChannel);
  }
  
  Future<void> showLiveNotification({
    required String courseName,
    required int minutesUntil,
  }) async {
    const androidDetails = AndroidNotificationDetails(
      channelId,
      channelName,
      channelDescription: '实时显示课程倒计时',
      importance: Importance.high,
      priority: Priority.high,
      ongoing: true, // 常驻通知栏
      autoCancel: false,
      showWhen: false,
      usesChronometer: false,
      styleInformation: BigTextStyleInformation(''),
    );
    
    await flutterLocalNotificationsPlugin.show(
      0,
      '下节课: $courseName',
      '还有 $minutesUntil 分钟开始',
      const NotificationDetails(android: androidDetails),
    );
  }
}
```
