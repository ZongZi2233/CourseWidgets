### 3. ✅ 首次进入软件无法切换周次和星期
**问题描述**: 
- 首次安装软件后导入测试数据或课表文件，无法切换周次和星期
- 更新软件（即使是相同安装包）再打开就正常了

**根本原因**: 
- `loadSavedData()` 中的 `_jumpToCurrentDate()` 是异步方法
- 数据加载完成后立即返回，但跳转操作可能还没完成
- 导致 UI 渲染时周次和星期还是默认值

**修复方案**:
使用 `Future.microtask` 确保在下一个事件循环中执行跳转操作

```dart
Future<void> loadSavedData() async {
  _isLoading = true;
  _errorMessage = null;
  notifyListeners();

  try {
    final courses = await _importService.getAllCourses();
    if (courses.isNotEmpty) {
      _courses = courses;
      
      // [v2.3.0修复] 确保数据加载完成后再跳转
      // 使用 Future.microtask 确保在下一个事件循环中执行
      await Future.microtask(() async {
        await _jumpToCurrentDate();
        debugPrint('✅ 数据加载完成，已跳转到当前日期：第 $_currentWeek 周，星期 $_currentDay');
      });
    } else {
      // 没有数据时，确保周次和星期有效
      if (_currentWeek < 1) _currentWeek = 1;
      if (_currentDay < 1 || _currentDay > 7) _currentDay = 1;
      debugPrint('⚠️ 没有课程数据，使用默认周次和星期');
    }
  } catch (e) {
    _errorMessage = '加载数据失败: $e';
    debugPrint('❌ 加载数据失败: $e');
  }
  
  _isLoading = false;
  notifyListeners();
}
```

**文件**: `lib/providers/schedule_provider.dart`

### 4. ✅ Windows 端没有通知、托盘和后台常驻
**问题描述**: 
- Windows 端关闭软件后进程就退出了
- 没有托盘图标
- 没有后台常驻
- 没有课程提醒通知

**根本原因**:
- 窗口关闭时没有阻止默认的退出行为
- 需要设置 `setPreventClose(true)` 来阻止窗口关闭时退出进程

**修复方案**:

1. **在 main.dart 中设置窗口关闭行为**:
```dart
if (Platform.isWindows) {
  // 设置窗口关闭时不退出应用，而是隐藏到托盘
  await windowManager.setPreventClose(true);
  
  final tray = WindowsTrayService();
  await tray.initialize();
  debugPrint('✅ Windows 托盘服务已在 main 中初始化');
}
```

2. **在 WindowsCustomWindow 中处理窗口关闭事件**:
```dart
@override
Future<void> onWindowClose() async {
  // 阻止窗口关闭，改为隐藏到托盘
  await windowManager.hide();
  
  // 进入后台模式
  final tray = WindowsTrayService();
  await tray.enterBackgroundMode();
  
  debugPrint('🌙 窗口已最小化到托盘，进程继续运行');
}
```

3. **增强托盘服务初始化错误处理**:
```dart
WidgetsBinding.instance.addPostFrameCallback((_) async {
  if (!mounted) return;
  
  try {
    final tray = WindowsTrayService();
    await tray.initialize();
    
    // 启动课程提醒
    if (mounted) {
      final provider = context.read<ScheduleProvider>();
      tray.startCourseReminder(provider);
    }
    
    debugPrint('✅ Windows 托盘服务已初始化并启动课程提醒');
  } catch (e) {
    debugPrint('❌ 托盘服务初始化失败: $e');
  }
});
```

## 技术细节

### Future.microtask 的作用
- `Future.microtask` 将任务放入微任务队列
- 确保在当前同步代码执行完成后，下一个事件循环开始前执行
- 比 `Future.delayed(Duration.zero)` 更快，优先级更高
- 适合用于需要在当前帧完成后立即执行的异步操作

### window_manager.setPreventClose
- 阻止窗口关闭时的默认退出行为
- 必须配合 `WindowListener.onWindowClose` 使用
- 在 `onWindowClose` 中自定义关闭行为（如隐藏到托盘）
- 这是实现 Windows 托盘应用的关键

### GlassButton API 正确用法
```dart
GlassButton.custom(
  quality: GlassQuality.premium,  // ✅ 直接在这里
  settings: LiquidGlassSettings(  // ✅ 不在这里
    glassColor: ...,
    blur: ...,
    thickness: ...,
  ),
)
```
